# 未文档化数据接口的发现

## 触发条件

- **页面是空壳**：所有路由（含乱编的路径）都返回同一个 HTML，正文只有「正在加载…」
- **要的数据 HTML 里根本没有**，但它一定在页面上显示过
- **免费接口被测出是阉割版**，需要找到完整接口
- 要拿某平台的数据/定价/额度，但它没有公开文档
- 想确认一个平台的 API 能力边界（有哪些接口、返回哪些字段）

与 `blocked-page-recovery` 的分工：那个管「被墙/付费墙/归档恢复」，
这个管「页面拿得到但数据不在里面，去把接口挖出来」。

## 核心判断：内容在客户端渲染的，就别再猜 URL

**信号**：`/docs`、`/api`、`/openapi.json`、`/随便编一个` 返回的都是**同一个字节数的 HTML**。

实测一个 Next.js 站，`/docs`、`/docs/api`、`/openapi.json`、`/docs/guide` 全部返回
同一个 44291 字节的外壳，正文只有一句 `正在加载文档…`。

**此时正确的动作是「去 bundle 里找接口调用」，不是继续猜路径。**

## 主流程（Next.js / Vue / React 通用）

```bash
UA="Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120 Safari/537.36"

# ① 拿页面，列出它加载的所有 chunk
curl -sL -A "$UA" "$URL" -o page.html
grep -oE '(src|href)="[^"]+\.js"' page.html | sort -u

# ② 全量下载（Next.js 在 /_next/static/chunks/），合并
for C in <chunk 列表>; do curl -sL -A "$UA" "https://<host>/_next/static/chunks/$C.js" -o "c_$C.js"; done
cat c_*.js > all.js

# ③ 挖接口路径 —— 这一步几乎总能命中
grep -oE '"/[a-z0-9/_.-]{4,60}"' all.js | sort -u

# ④ 只想看某页的 chunk 时，直接搜那一个
curl -sL -A "$UA" ".../app/<page>/page-<hash>.js" -o p.js
grep -oE '"(/[a-zA-Z0-9/_.$-]*)"' p.js | sort -u
```

**为什么命中率高**：接口路径、参数名、错误文案常以**字符串常量**形式留在 chunk 里。
本次一口气挖出 43 条 `/open-interface/v1/...` 路径，其中返回整站 API 文档 JSON 的
那个（**无需登录**）就是靠这招找到的——一下子拿到 13 篇完整接口文档。

## 两个补充挖法

### `self.__next_f.push` flight data

Next.js 会把首屏数据内嵌在 HTML 里：

```python
import re, json
h = open("page.html", encoding="utf-8", errors="replace").read()
for c in re.findall(r'self\.__next_f\.push\(\[1,\s*("[\s\S]*?")\]\)', h):
    try: s = json.loads(c)
    except Exception: continue
    if any(k in s for k in ("接口", "api", "doc")): print(s[:2000])
```

有时数据直接在里面，省掉整个抓接口环节。

### 中文串筛选——UI 文案会直接暴露功能边界

```python
strs = set(re.findall(r'"([^"\\\n]{2,80})"', js))
zh = sorted(x for x in strs if re.search(r'[\u4e00-\u9fff]', x))
kw = ("价", "费", "额", "套餐", "权限", "认证", "免费", "试用", "次")
print([x for x in zh if any(k in x for k in kw)])
```

本次靠这招从控制台 chunk 里挖出页面上**看不到**的规则原文：
「会员购买后即时生效，有效期为1年」「调用额度按自然年计算，每年1月1日重置」
「升级会员后，剩余调用额度将叠加计算」——这些是定价决策的关键输入。

## 拿到接口后：先验活，再写进流程

**SPA 里的路径不等于可用路径**：可能带前端拼接的参数（`?page=`）、可能需要特定
Referer/UA、可能需要登录。**逐个 GET 一遍，把状态码全打出来**，比看代码猜快得多。

```bash
for P in "/api/v1/a" "/api/v1/b" "/api/v2/c"; do
  code=$(curl -s -o r.json -w "%{http_code}" -A "$UA" --max-time 15 \
    -H "Referer: https://<host>/" "https://<api-host>$P")
  printf "%s size=%-7s %s\n" "$code" "$(wc -c < r.json)" "$P"
  head -c 260 r.json; echo
done
```

**状态码语义**（本次实测）：
- `200 + 长 JSON` = 可用
- `200 + {"code":1010,"message":"缺少 AccessToken"}` = **路由存在**，只是要鉴权（比 404 有价值得多）
- `404 page not found`（纯文本 18 字节）= 路径不存在
- `200 + size=0` = 路径存在但参数不对

## 验活之后：签名鉴权类平台的三个坑

国内开放平台常见 `app_id + timestamp + sign(MD5)` 这套。**踩过的三个坑，按这个顺序查：**

### ① 文档给的 sign 样例值可能是假的

实测某平台文档写 `sign(app_id=boohee, timestamp=1470042310, app_key=12345) =
27f61732856d133758e7f8927a3abed1`。把 **8 种拼接变体**（等号 / 冒号 / `&` /
只前置 / 只后置 / 不包 / 多带字段…）全算一遍，**没有一个能对上**。

→ **按文字描述实现，不要拿样例值反推算法。** 否则会一直以为自己写错了，
在一个根本不可能对上的目标上反复试。

### ② 时间戳必须用服务器时间——本机差几分钟就失败

报「时间戳非法」时，**先别改签名**。实测本机 epoch 比服务器快 2–3 分钟就被拒；
±8h、毫秒 / 秒、字符串 / 数字 **全部无效**。

**取服务器时间的笨办法最好用**——任何该平台自己的公开响应里几乎都带 `now`：

```bash
curl -s "<api-host>/<任意公开接口>"
# → {"code":1010,"message":"缺少 AccessToken","now":1792373917}
```

用这个 `now` 当 timestamp 后，错误码**立刻**从「时间戳非法」变成「app_id/key 无效」——
**错误码的变化本身就是进度条。**

### ③ 错误码有检查顺序，这就是诊断线索

```
1014 时间戳非法   ← 最先检查；不通过根本不会验 app_id/app_key/sign
1001 缺少 app_id/app_key
1002 无效的 app_id/app_key
1003 sign 非法
1010/1011/1012 令牌缺失/过期/无效
```

→ **看到 1014 就去修时间戳，不要在签名上浪费时间；
看到 1002 才说明前两关都过了。**

✅ **请求体格式通常不是坑**：JSON / form-urlencoded / query string 三种都能走到
签名校验、报同样的错。**别在这上面试太久。**

⚠️ **凭证字段名要先确认再试**：控制台常见 `App ID`（明文显示）+ `App Secret`
（提示「仅完整展示一次」）两个字段。**用户只发来一个时别硬试**——
32 位随机长串通常是 Secret，去把 App ID 要回来。

⚠️ 调这类域名照旧要带浏览器 UA + 挂代理，否则被 WAF 拦。

## 判定「免费接口是不是阉割版」

看到免费接口返回的字段**明显少于界面展示的内容**时，那是商业分层，不是 bug。

实测同一个平台：
- **免费公开接口**：返回 `name` / `calory` / `carbohydrate` 三个字段 + 一个
  `food_type` 类型标记 —— **只有热量和碳水，没有蛋白/脂肪/钠**
- **付费开放平台接口**：返回热量、蛋白/脂肪/碳水（含细分）、15 种维生素、
  多种矿物质，还带 `lights`/`warnings` 业务标记

**结论口径**：「免费接口能拿到 A，完整数据在 X 接口」——把边界说清楚，
不要让用户以为免费版就等于全部。

### 🔴🔴 但反过来也要防：「被阉割」的结论**可能只对那一个接口成立**

挖出那条免费接口后我写下了上面这段「免费只有热量+碳水」的结论。**当晚被自己推翻：**
同一个域名下**还有另一个公开接口** `/fb/v1/foods/<code>`，它**给完整营养素**
（蛋白/脂肪/碳水细分、钠、胆固醇、那个平台自己加的**嘌呤**列），
外加 `units[]`（“一个多重”）和 `is_liquid`——**全免费、无需鉴权、零额度消耗**。

而**付费**的 `/api/v2/foods/:code/units` 拿同样的 `units` 却报「权限不足」。

**所以两条教训：**

1. **别把「一个免费接口被阉割」推广成「这平台的免费接口都是阉割版」** ——
   同一个站点常常夹着多套公开接口（区分：搜索类 / 详情类 / 列表类），
   它们的字段完整度可以差很大。**看到一条就下结论 = 会误到用户。**
2. 🔴 **「付费接口要会员」≠「这份数据要会员」。**
   看到付费接口报「权限不足」时，**先去找同数据的公开入口**，再决定要不要掏钱。
   本次差点就凭付费接口的报错建议用户买 365 元会员，而那数据是白给的。

**具体动作**：拿到一个返回残缺的公开接口后，用它的**主键（如 `code`）** 去试
同域名下的其他路径形状（`/v1/foods/<code>`、`/v1/foods/<code>/detail` …），
并**对比付费接口文档里的返回字段**——付费文档就是你的探测清单。

### ⚠️ 公开接口普遍有频率限制，批量抓取必须慢

实测：连打十几个请求后整个域名**所有**公开接口开始返回
`HTTP 429 Too Many Requests`，**包括之前成功的那些**。

**建本地缓存表时必须三条齐备**：
- **慢**：每请求间隔 2.5s 起
- **指数退避**：撞 429 后 3s / 6s / 9s…，连续失败则停 20s
- **逐条落盘**：**每抓一条立即写文件**，不是跑完再存——否则 429 一来全白跑

🔴 **别删缓存文件重抓**。本会话为了改排序规则删了整张表，重抓时正好撞上限流，
**已抓到手的数据全丢**。要改规则就单条删。

## 定价/额度信息的挖法

定价页常写「注册后可见」/「暂无可购买套餐」——**未登录时拿不到**。但：

1. **定价页的文案本身有价值**：实测挖到「阅读 API 文档，注册登录获取 Key，
   **零成本验证接入方案**」→ 说明有免费试用额度
2. **用户协议/服务条款是公开的，而且写到很细**：用 `market_page?title=<条款名>`
   这类接口按标题取。实测从条款里挖到「免费调用额度以网站公示为准，超出部分……
   需升级为会员后继续使用」和「会员到期停接口，但**可在免费权限内自主导出留存**」
   ——**后者直接决定了一个商业方案的可行性**
3. **控制台 chunk**：见上面的中文串筛选
4. 挖不到就**明说挖不到**，列出需要用户登录后看的具体项，不要猜数字

## 合规：找到 ≠ 能用

**发现了接口不等于可以批量调用。**给用户结论时必须同时给出条款原文。

实测两类条款的区别（这个区分很关键）：
- ❌ **禁止类**：「不得私自爬取、搬运、二次拆解商用」「不得转租、转售、转授权、
  拆分二次分发」
- ✅ **允许类**：「您可在免费权限内自主导出留存」

**个人自用 与 商用 不是一回事，但批量抓取属于灰色地带。
把原文摆出来，让用户自己拍板——不要替他决定，也不要含糊过去。**

## 本机环境

- 走代理：`export HTTPS_PROXY=http://127.0.0.1:10808 HTTP_PROXY=http://127.0.0.1:10808`
- 必须带浏览器 UA（默认 urllib UA 会被 Cloudflare 类 WAF 拦）
- MSYS 下 curl 的 `-o /tmp/x.json` 会写不出文件 → **先 `cd "$LOCALAPPDATA/Temp"` 再用相对文件名**
- 大量 chunk 合并后统一 grep，比逐文件搜快得多
- 解析脚本写成 `write_file` 落到 `$LOCALAPPDATA/Temp/*.py` 再跑，避开 bash 引号地狱
