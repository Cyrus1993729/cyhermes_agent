# Opus 设计的「先看这里」AI 分析板块（跨境日报顶部，2026-08-07 落地）

用户需求：日报不能只有新闻清单，还要有一段"AI 分析"——给**未来想做跨境电商的小白**（33 岁中文用户，未入场、无电商金融背景）用大白话分析当天新闻。形式设计交给 Opus，本文件是其完整设计（已固化进 16:00 cron prompt）。

## 形式
- **标题**：「先看这里 · 今天该知道的 3 件事」（不叫"AI 分析"，太冷太机器）
- **位置**：日报**最顶部**（新闻清单之前）——用户 16:00 打开时注意力有限，分析给入口，再决定看不看清单
- **篇幅**：450-600 字，超 600 = 在复述新闻不是分析
- **语言**：像入行 5 年的朋友微信解释，第二人称"你"，短句，可直说"别碰/这事跟你没关系/说白了"

## 结构（三段式变体，推荐理由：解决小白"信息过载+无法行动"两个痛点）
```
导语（1-2句）：今天 N 条里，跟你现在阶段有关的是哪几件；具体列举 2-3 条可跳过的
├─ 事件 1
├─ 事件 2  ─ 每件事固定三段：发生了什么 / 说人话 / 对你意味着什么
└─ 事件 3  ┘
结尾：今天你要做的（允许是"什么都不用做"）
```
- "事件"≠"新闻条"：多条相关新闻必须合并成一件事（如关税三条：免税取消+退还1000亿+25州起诉 → 合成"美国关税这盘棋还在乱着"）
- 选事标准：能改变他**选平台、选品类、算成本**三决策之一的才入选；落不到的直说"跟你没关系"

## 风格硬规则
- 行话：每篇最多 2 个新术语，格式固定"人话（行话叫 XX）"（GMV → "卖出去的货值多少钱"）；他今天用不上的词别教
- 不确定度词：解读必须带"大概率/我的理解是/看起来"；超出新闻的推断标注"（这是我的推测）"；禁"业内普遍认为"
- 建议四档：现在就做（10分钟内零成本）/ 先记着（3个月后用得上）/ 别碰（明确的坑）/ 不用管（导语打包跳过）
- 禁词：关注一下、持续观察、重视起来、了解相关政策、赋能、闭环、抓手、生态位
- **允许"今天什么都不用做"**——未入场者大多数天确实无事可做，硬编行动消耗信任
- 优先保证每天至少 1 件事是"具体的坑"（合规踩坑/账号风险/选品禁区）——长期价值最高的内容
