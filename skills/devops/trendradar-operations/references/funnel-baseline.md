# 漏斗统计方法与数量级基线

## 统计方法（stats_funnel.py）
1. 取最新一天库：`sorted(glob(output/news/*.db))[-1]`
2. 一次全量抓取 = `MAX(last_crawl_time)` 批次
3. 白名单命中：`matches_word_groups(title, groups, filter_words, global_filters)`（frequency_words.txt v1.0）
4. 归一化去重：小写 + `re.sub(r"[\s\W_]+","",t)` + 去修饰词
5. 分领域统计：逐个组测 `matches_word_groups(title, [group], ...)`

## 基线（2026-08-07 实测，v1.0 关键词）
```
单次抓取全量:      255 条（11 平台，MAX(last_crawl_time) 批次）
→ 白名单命中:      42 条（16%）
→ 归一化去重:      41 条（最终候选数）

窗口累积（morning 窗口：昨天 18:00→现在，两天库全量去重）:
→ 全量去重:        376 条
→ 白名单命中:      57 条（29%）
```
- 分领域（单次抓取，标题级可多组命中）：中国科技 20、美股 11、AI半导体 7、宏观 7、黄金 4、**跨境电商 0**
- 含义：LLM 精选输入通常 40-60 条（白名单后），每天 2 次 token 成本可控（几毛/天）
- 若某领域新闻特别多，可考虑领域配额（保底每条领域 1-2 条）防挤占

## 🔴 统计口径铁律：先筛后截断
- `prepare_candidates.py` 的 `MAX_CANDIDATES=80` 截断**必须放在白名单过滤之后**
- 若先截断再筛选：实测白名单命中从 57 掉到 23（34 条候选被截断丢失）——统计/管线结果都会失真
- 教训来源：用户质疑"跨境 0 条是低频吗"→ 排查发现是候选池前 80 条截断导致。全量窗口验证后跨境确实 0 条（真实低频），但截断 bug 是真实存在的独立问题

## 📌 跨境低频是客观事实（机制澄清）
- 连续多批次（昨晚窗口 + 最新抓取）跨境电商关键词全部 0 命中——真实低频，非统计错误
- **采集是全量的、关键词只用于筛选**：TrendRadar 抓取不分关键词，所有平台新闻入库；我的管线每次运行实时用最新关键词过滤 → 新关键词对历史已抓数据立即生效，不存在"旧关键词池子"
- 热榜 = 大众热点，跨境 = 垂直行业：跨境新闻平时难上榜，只有 T86 突变、平台大事件（Temu/SHEIN 动态）、关税政策这类全网级新闻才会出现
- 精选规则：跨境出现即优先保留（稀缺 = 出现必重要）；板块缺席属常态，不硬凑
