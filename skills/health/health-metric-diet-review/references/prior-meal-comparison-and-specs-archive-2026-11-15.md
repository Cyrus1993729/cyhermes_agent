# 2026-11-15：拿「今天」和「以前某一顿」做对比时，两次翻车

用户原话：

> 「你瞎说那天我们自己评判的一顿螺蝴网螺蝴粉的脂肪多少呀？你不能只看它的油包呀，
> 还有炸蛋，还有猪蹄，还有虎皮鸡爪，还有腊肠等等那么一大堆呢？它的钠跟嘴呤也没好哪去啊。」

他说“网螺蝴粉”是语音转写误差，指的就是我们之前算过的那顿。

## 错在哪里（两层，缺一不可）

### 错一：拿通用值顶掉了我们自己算过的数

我把螺蝴粉当成“一份包装食品”，凭“油包 20–25 g 脂肪”估了个区间就下结论。
实际上这顿早在 `~/health/tools/specs/_1113_yz.py` 里算过完整版：
**螺蝴粉全汤＋多加辣＋深炸蛋＋虎皮凤爪＋猪蹄＋腊肠**。

### 错二：拿“今天全天四餐”去比“人家的单餐”

口径根本不对等。正确比法是 **单餐对单餐**，或者明说“我拿全天比它单餐，只是量级参考”。

## 一个必须记住的归档事实

🔴 **那次“咨询预估”当时明确说了不落盘，所以 `diet/*.md` 里搜不到。**
它躺在 `~/health/tools/specs/*.py` 里。

所以明年再碰到“我们之前算过的那顿”，搜索顺序是：

```
1. ~/health/diet/*.md           已经入档的餐次
2. ~/health/tools/specs/*.py    咨询预估、敏感性分析（本次就是这类）
3. ~/health/reviews/*.md        专题分析归档
```

**`specs/` 里常有同名多版**（本次就有 `_1113_lsf.py` 简版和 `_1113_yz.py` 完整版），
简版漏了猪蹄和腊肠，直接用会把对比做偏。**取食材最全的那版**，并跑一遍拿现成输出。

## 正确的对比（单餐对单餐）

拿今天最重的晚餐（1073.25 卡）去比：

| | 那顿螺蝴粉 | 今天晚餐 | 谁更重 |
|---|---:|---:|---|
| 热量 | 1649.98 | 1073.25 | 螺蝴粉高 54% |
| 脂肪 | 113.79 | 58.26 | 螺蝴粉高 **95%** |
| 钠 | 4567.78 | 1905.17 | 螺蝴粉高 **140%** |
| 嘴呤 | 531.01 | 516.57 | 基本持平 |
| 蛋白 | 65.51 | 76.41 | 今天略高 |
| 纤维 | 2.23 | 4.72 | 今天高一倍 |

**他说的“强太多”是对的**：今天全天四餐加起来钠 3341.21，还没赶上一顿螺蝴粉的 4567.78。

## 但他“嘴呤也没好哪去”这句只对一半

那顿单餐嘴呤 **531.01**，今天晚餐单餐 **516.57**——**几乎一样，甚至略低**。
今天全天 847.18 显得高，是因为叠了三餐肉，不是那顿更差。

→ **不要因为总结论对他有利，就把存疑的那一项也顺着说成“好”。**
他原话里同时包含一个对的判断（脂肪/钠）和一个错的判断（嘴呤），要分开回答。

## 规则

1. **他提到“上次那顿/我们自己算过的那顿” → 先搜 `diet/` 和 `specs/`，不许用通用值。**
2. **同类比同类**：餐对餐、天对天。拿不同层级对比必须明说。
3. **`specs/` 同名多版取最全的那版**，并注意文件末尾自带的历史对比段可能过期。
4. 他的对比判断常同时含对错两项，拆开逐项判，不要整句附和也不要整句否定。
