# 每日营养摄入方案（减脂 / 增肌 / 身体重组）

## Trigger
- "我想减脂增肌，每天三大营养素摄入多少比较合适"
- "我 XXkg、体脂 XX%，想刷脂应该怎么安排营养摄入"
- 用户贴出饮食 App 截图问"这算的对不对"
- 用户报出今日摄入（热量 + 三大营养素）要求评估

## 🔴 铁律一：按 g/kg 定档，不按百分比
百分比的坑：热量目标一变，百分比算出来的克数跟着变，**蛋白质会被稀释**。
正确顺序：**先钉蛋白质 → 再钉脂肪下限 → 碳水 = 剩余热量**。顺序不能反。

## 🔴 铁律二：报数先自检，再分析
见下方「第六步」。**永远不要拿未校验的输入做分析。**

## 第一步：拿身体基线
需要：体重、体脂率（有最好）、年龄、每周训练次数。

- **有体脂率就用 Katch-McArdle**：`BMR = 370 + 21.6 × 去脂体重(kg)`，其中 `去脂体重 = 体重 × (1 − 体脂率)`
  → **不依赖身高**。身高 170–180cm 只造成约 ±60 kcal 差异（<4%），**不必为身高多问一轮**。
- 没体脂率才退回 Mifflin-St Jeor：`10×体重 + 6.25×身高 − 5×年龄 + 5`

## 第二步：TDEE
```
久坐 / 不练          1.2
轻活动  每周 1-3 练  1.375
中度    每周 3-5 练  1.55
高度    每周 6-7 练  1.725
```
`TDEE = BMR × 系数`

## 第三步：热量目标
| 目标 | 热量 |
|:--|:--|
| 刷脂 | TDEE × 0.82（赤字 15–20%） |
| 重组 / 维持 | TDEE 或 TDEE − 200 |
| 增肌 | TDEE + 200~350 |

**不要大赤字。** 赤字一大就不是"重组"而是"掉肌肉"。

## 第四步：三大营养素
| 目标 | 蛋白质 | 脂肪 | 碳水 |
|:--|:--|:--|:--|
| 通用维持/增肌 | 1.6–2.2 g/kg | 0.8–1.0 g/kg | 剩余 |
| **刷脂 / 重组** | **2.0–2.4 g/kg** | **0.8–1.0 g/kg** | 剩余 |

`碳水(g) = (热量目标 − 蛋白g×4 − 脂肪g×9) ÷ 4`

## 第五步：安全线与节奏
- 脂肪 **安全下限 0.6 g/kg**（低于此影响睾酮与脂溶性维生素 A/D/E/K 吸收）
- 蛋白质 **通用下限 1.6 g/kg**
- 每周减重 **≤ 体重的 1%**（80kg → 0.8kg/周；推荐 0.5kg/周）
- 每减 **5kg 重算一次**（BMR 随体重下降）
- 8–12 周安排一周维持期
- 蛋白分餐：每餐 0.5–0.6 g/kg 或 ≥30–40g，一天 3–4 餐；睡前 30–40g 有助夜间保肌

## 第六步：🔴 强制算术自检用户报的摄入数据
用户报「今天吃了 X 大卡、蛋白 A、碳水 B、脂肪 C」时，**先算**：
```
校验值 = A×4 + B×4 + C×9
```
和 X 对不上 → 数据有问题，**不要直接拿去分析**。

**反推定位错在哪一项**：把 X 和其中两项当真，反推第三项：
```
碳水反推 = (X − 蛋白×4 − 脂肪×9) ÷ 4
```
再拿反推值跟用户/App **自己描述的实物**（如"碳水大头是西瓜36g + 两顿米饭44g"）比对——
吻合的那组说明哪两项是对的，**剩下那项才是错的**。

### 实踩（2026-10-18）
某健康 App 报「蛋白 98g / 脂肪 24g / 碳水 210g / 总热量 910 大卡」。
- 反算 `98×4 + 210×4 + 24×9 = 1448 ≠ 910` → 对不上
- 用 910 反推碳水 = **75.5g**，而 App 自己说碳水大头是「西瓜 36g + 两顿米饭 44g = 80g」→ **吻合**
- 结论：**「碳水 210g」是错的，真实 ≈76g**

## 🔴 消费者健康 App 会给出危险背书
同一个 App 把两个严重不达标的项评价成了健康：

| App 原话 | 实际 | 判定 |
|:--|:--|:--|
| 「蛋白 98 克，对你这个运动量刚好够」 | 98÷80 = **1.23 g/kg**（需要 160–192g） | ❌ 连通用下限 1.6 都不到 |
| 「脂肪 24 克，落在正常范围里，不算低也不算高」 | 24÷80 = **0.30 g/kg**（安全线 48g） | 🔴 连下限一半都不到 |

**这是把严重欠食说成健康。** 用户贴这类截图时，**不要沿用它的定性结论**，
一律按 g/kg 重新算，并明确指出它的判断错在哪。

## Pitfalls
- 🔴 **"200g 碳水"极可能是"200g 主食"**：200g 熟米饭只有约 50g 碳水，**差 4 倍**。
  这是消费者饮食记录最大的误差来源，必须反问确认。
- 🔴 **不要心算**：克数/kcal 换算、"补齐到目标还差多少"这类多步运算一律走 execute_code。
- 🔴 **身体重组的适用人群有限**：效果最好的是**新手、停练复训者、体脂偏高者**。
  练了多年且体脂已低的人重组极慢 → 建议**分阶段**（先减脂再增肌），别让用户硬扛重组。
- **体重基数大的人**蛋白按"目标体重"或"去脂体重"算更合适，不要按当下总重。
- **抗阻训练是前提不是选项**。只靠饮食制造赤字，掉的一半是肌肉。
- 汇报用 bullet / 标签行，**不要用 markdown 表格**（Telegram 不渲染表格）。

## 参考数据（外部来源）
- 2026 共识：重组期蛋白 **2.0–2.4 g/kg**；训练人群 1.6–2.2；50 岁以上 1.4–1.8（每餐 35–40g）
- **Longland 2016 (AJCN)**：热量赤字下 2.4 g/kg 蛋白 + 抗阻训练，4 周**减脂 4.5kg 同时增肌 1.2kg**（年轻男性）——重组领域标志性研究
- 脂肪按"地板营养素"处理：先满足下限，剩余热量才给碳水
