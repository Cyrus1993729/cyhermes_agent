# 健康域派活任务书模板（主 Hermes → 健康助理）

> 2026-11-17 单一会话内跑了 5 轮派活，这套写法是验证过的。主 Hermes **不做核算**，只写任务书 + 转述回执。

## 为什么需要任务书

`hermes -p health chat` 是**有历史会话的**（会 `Resumed session`）。模型会继承上一轮的结论和口气，所以：
- 新口径必须显式覆盖旧口径，并明确写「上一轮那个备选作废」
- 不写禁止项，它会自作主张扩活儿（写 md、写档案、给建议）

## 调用方式

```bash
# 长 prompt 一律走 --query-file，不要 $(cat f)
hermes -p health chat -c "Bot Chat" -m deepseek-v4.1-flash \
  -Q --query-file "C:/Users/Administrator/AppData/Local/hermes/cache/query_<主题>_<日期>.txt" \
  > "$LOCALAPPDATA/Temp/health_<主题>_<日期>.txt" 2>&1
```

后台跑：`terminal(background=True, notify=True)`，完成后 read_file 回执原文，**原样转给用户，禁止压成摘要**。

## 任务书七段（缺一段就出问题）

### 1. 一句话
本轮要它干什么，一句话说完。

### 2. 日期与档案
```
今天：YYYY-MM-DD（周X）
当日档案：C:\Users\Administrator\health\diet\YYYY-MM-DD.md（字节数，mtime）
档案已有小节：《早餐》《午餐》《加餐》《今日汇总（截至 HH:MM）》
晚餐小节不存在  ← 明确说缺哪个，否则它会重写已有的
```

### 3. 用户原话（逐字，未改写）
引用块形式。**别替他改写，别替他总结**。他后来的补正（如「猪肉只有150克」）要标注「以此为准，前一条作废」。

### 4. 已定口径（本轮不许再动）
上一轮拍板的东西列出来，并写「**不再有第二档**」。他拍板后最烦的就是回执里又挂一个备选。

### 5. 核算口径
- 半份/整份怎么分
- 哪些克数是他报的，哪些要按单重换算（并要它把换算过程写出来给他看）
- 哪些调料没报量 → 按常见配比估，**明标估算，不要他核**

### 6. 禁止项（每轮都要重写，不能省）
```
- 本轮只核算，不写任何文件（diet/ reviews/ profile.md skill 全不动）
- 收尾自报「本轮没有写任何文件」+ 回读字节数/mtime 作证
- 「打算吃」的餐不许进今天合计（未发生不进统计）
- 不写劝诫、不评食谱好坏、不给改进建议
- 不许用「占额度 xx%」这类预算式语言评钠/嘌呤
- 不许为了维护上一轮结论而辩护
```

### 7. 交付格式
```
1. 结论先行（一句话，数字齐全）
2. 逐项一行，字段齐（热量/蛋白/脂肪/碳水/纤维/钠/钙/嘌呤）+ 来源标签
3. 合计行 + 来源图例
4. 单列「数据完整性检查」
5. 单列「换算过程」
6. 单列「边界自查」
```

## 两段式铁律

```
① 核算稿（不落盘）→ ② 他确认 → ③ 才写入档案
```

**他要的确认必须是他凭常识能判断的**（菜名、份量、猪肉是瘦是肥）。
专业细节（放了多少糖、换算精度）**绝不落到他头上**——算好给他看并标估算。

## 写入轮（第 ③ 步）额外要求

- 格式要与档案里既有的早/午/加餐小节**同构**（同列、同表头）
- 🔴 **「今日汇总」小节必须重出**：时间戳更新 + 四餐相加 + 保留「运动未报」状态。
  只加晚餐不重出汇总 = 没记完。
- 汇总里不写「赤字」「超标」，只写「还差 / 已超 + 数值」
- 回读验证：grep 晚餐小节标题 + 合计行 + 汇总行，贴原文输出

## 已确认的长期口径

- **纤维目标 = 25 g**（指南区间下限）。2026-11-17 它建议改成 28 g（14 g/1000 kcal × 2000），**用户否决**，别再提。
- 猪肉包装读不出营养表时按「猪肉(瘦)」口径；他说瘦就定瘦，不许再挂肥瘦备选。
- 燕麦/钢切燕麦库内**无标准 exact 条目**，只有品牌 partial 条，替代误差要如实报。
- 薄荷额度看 `health/fooddb/boohee_api/quota.json`，紧张就全免费路径。

## 转述纪律

- 回执**原样搬**，长就分条发，**绝不压成摘要**（踩过：午餐回执被压成摘要，他说没看到回执）
- 它自报「没有写文件」，你要**自己 stat 一遍字节数/mtime 复核**，不听口说
- 它推翻了上一轮的判断时（如 VE 那条），**主 Hermes 要明说「我之前跟着说的那句是错的」**，不要悄悄改口
