# 派活产出「方案类文档」的验收（2026-11-02 早餐方案实战）

> 场景与「单餐核算」不同：他不要一顿饭的数字，而是问「有没有别的建议」（早餐吃腻了 / 想换主食 / 要不要加蛋白）。
> 健康助理产出的是一份多套方案的长文档（本次 8 套、344 行）。
> **单餐核算的验收管的是「数字对不对」；方案类文档的验收还必须管「和 profile 已有的硬指标打不打架」。**

## 一、验收 4 件（缺一件就别报给他）

| # | 动作 | 判据 |
|---|---|---|
| 1 | 逐项 vs 来源库 | 每行 = `每100g 值 × 克数`，与 `foods.json` / `official_extra.json` / `cache.json` 逐项比 |
| 2 | 合计 = 逐项和 | 热量/蛋白/脂肪/碳水/纤维/钠/钙 七列全加一遍 |
| 3 | code 真伪 | 免费 `public_detail(code)` 逐个回查（code 不在本地 cache 里**不代表编造**，先调接口） |
| 4 | 🔴 **与 profile 硬指标对照** | 方案里每一项做法都要能对上 `profile.md` 第五节的「其他硬指标」 |

第 4 条是本次唯一漏掉的，代价是返工一整轮。

## 二、🔴 实例：鸡蛋数量与 profile 打架（本次漏项）

`profile.md` 第五节「其他硬指标（指南）」写着 **「鸡蛋 1 个/天」**。
健康助理的 8 套方案里 **S3、S8 各用 2 个全蛋**，全文 0 处解释「这里为什么可以吃 2 个」。

- 派活时我在任务书里写了「鼓励低脂奶、鸡蛋」，它据此堆蛋白 → 冲过了 1 个/天的线
- **任务书没写的东西，它会用自己的营养学判断补**；所以要拿 profile 的硬指标当验收项，不是当背景资料
- 修正后的数值（1 个全蛋 + 2 个蛋清）反而更好，说明**约束不是妥协**：

```
S3 紫薯蛋奶碗   2 全蛋 → 488.8 卡 / 蛋白 42.6 / 脂肪 9.1 / 胆固醇 668 mg
               1 全蛋+2 蛋清 → 458.9 卡 / 蛋白 43.7 / 脂肪 4.9 / 胆固醇 344 mg
S8 黑米小米粥   2 全蛋 → 468.2 卡 / 蛋白 40.1 / 脂肪 10.1 / 胆固醇 664 mg
               1 全蛋+2 蛋清 → 438.3 卡 / 蛋白 41.2 / 脂肪 5.9 / 胆固醇 340 mg
```

→ 蛋白 +1.1 g、脂肪 −4.2 g、胆固醇 −324 mg。**「少吃一个蛋黄会掉蛋白」是错觉**，蛋清的蛋白密度（11.6 g/100 g）只比全蛋（13.1）低一点，胆固醇是 0。

## 三、胆固醇口径分歧：两套数都在用，必须声明用哪套

| 口径 | 1 个蛋（50 g）胆固醇 | 出处 |
|---|---:|---|
| **中国食物成分表**（`foods.json` `111101x` 648 mg/100 g） | **324 mg** | 本地库，与其他所有数字同源 |
| USDA / 公开科普（约 186–200 mg/枚） | 约 200 mg | 媒体与科普常用 |

差 1.6 倍。**默认用成分表口径**（因为整张表其他数都是同源算的，混用会把一天算乱），
但档案里必须把另一档摆出来。

🔴 **关键：换口径不改变结论。** 按 200 mg/枚算，「2 个全蛋」= 400 mg，仍是 300 mg 上限的 **133%**。
所以「改成 1 个全蛋」这个结论对口径不敏感 —— 这类「结论对两种口径都成立」的验证值得做一遍，能免掉一轮争论。

《中国血脂管理指南（2023）》原文：**ASCVD 中高危与高胆固醇血症患者，每天膳食胆固醇 <300 mg**。
他 LDL-C 4.37 / TC 6.91 属高胆固醇血症 → 这条对他直接适用，不是人群泛泛建议。

## 四、派活「修正轮」的任务书要点

发现漏项后补一轮修正时，任务书必须写明：

1. **只改受影响的部分，不要把其他 6 套推倒重写**（否则它会顺手改口径，越改越乱）
2. 列出**已知正确的部分**（本次写了「逐项数据与来源库全部对得上、合计加总正确、付费 0 次」），
   避免它把已经验过的部分再动一遍
3. 把要它查的**出处**指明到指南级别，并允许它回答「查不到原文」（本次它把《成人高脂血症食养指南》的「<200 mg」标成二手转述，是对的做法）
4. 要求它按 profile 第六节的**三档口径**写结论：指南原文 / 临床惯例 / 机制推测

## 五、方案类文档还要查「单套合规 ≠ 全天合规」

单套早餐 43 g 蛋白、钠 200 mg 都合规，但**一天吃两套就撞车**。修正轮补的「一天总量视角」是有效的：

- 一天最多 1 个蛋黄；含蛋套 S2/S3/S4/S5/S6 一天只能选一套
- 奶当量一天 ≤400 g 左右（S3+S6 同天 = 450 g）
- S7（鸡胸，嘌呤 222）一周 ≤1–2 次，不能当主力

→ 给他的方案，末尾必须有一节「哪几套不能同天吃」，否则他会默认可以叠加。

## 六、数据核对脚本

逐项 vs 来源库的复核用 `scripts/verify_meal_rows.py`（本 skill 自带，见该脚本头部注释）。
`scripts/verify_diet_tables.py` 只核「合计 = 逐项和」，**不核逐项值与来源库是否一致**，两个都要跑。
