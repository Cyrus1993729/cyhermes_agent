# 拍照核餐的两个新坑 + 外卖预演评估口径（2026-11-02 实测）

> 场景：早餐口述直录 → 午餐五小碗照片 → 晚餐外卖点餐界面截图预演。
> 一整天连做三轮，暴露两类问题：**照片里的非食物被当成食物**、**外卖「打算吃」阶段怎么算**。

## 坑 1：餐具/背景被识别成食物

午餐照片右上角有一块「浅绿色椭圆形、表面光滑」的东西，视觉模型判成「青团／绿豆糕／抹茶点心」，
我据此写进任务书「⑤b 浅绿色椭圆糕点，约 40 g，**用户未提及，暂不计入，如已食用待补**」。

用户一句：**「5里面椭圆浅绿的东西是勺子底部」**。

### 处理法（照做，别改）

1. **照片里出现说不清的小物件时，不要自行计入、也不要静默剔除** —— 按「暂不计入 + 写明原因 + 待补」的措辞落进档案，
   然后在给用户的清单里**单列一行问他**。他一句话就能定，比继续放大猜快得多。
2. 他给了答案后，**回去把那句备注改掉**（改成「经用户确认为勺子底部，非食物」），
   不要留在档案里当悬案——否则以后回看会以为当时真有一块未确认的糕点。
3. 同理适用于：碟边、餐巾、筷子阴影、酱料碟、牙签、饮料杯里的柠檬片。

> 这条与他既定的偏好一致：**别为「模型读不清小字/认不准小物」死磕，摆出来让他改**（有人工核对）；
> 但**口径错（如卤汁算进摄入）必须自己修**。区分点：认不准 = 摆给他；算错了 = 自己改。

## 坑 2：他报实数会直接覆盖你的目测克数

- 我先按图片目测给了「红烧肉 160 g（8 块）、红烧鸡块可食 110 g、红烧萝卜丝 170 g」。
- 他并未逐条否掉，而是直接回：**「红烧肉120g 红烧鸡块可食用大概80g 红烧萝卜丝80g」**。

### 处理法

1. **他的数字一律覆盖我的目测值**，不去论证谁更准（他也不接受我拿 units 反推去说服他）。
2. **是整体重算，不是打补丁**：红烧肉 160→120 会让合计、供能比、自检、嘌呤表、汁档、敏感性档、早+午小计
   **全部跟着变**。实测这一改动了 **30+ 处**（表格 11 行 + 合计 + 供能比 + 自检 + 嘌呤表 5 行 + 汁档 2 行 + 敏感性 + 小计表 8 行 + 复核小节）。
   **别只改合计行**，`verify_diet_tables.py` 会立刻发现行和跟合计对不上。
3. 改完必跑 `verify_diet_tables.py <档案绝对路径>`（**直接传路径，它不认 `--help`**，会把它当成文件名去读然后 FileNotFoundError）。
4. 菜单式的「这道菜 80 g」是**整道菜的总量**，不是主料净重。要按比例往下拆（红烧萝卜丝 80 g → 白萝卜 70 g + 肉丝 10 g），
   **并在档案里标明拆分为估算、总量以他给的为准**。

## 坑 3：菜品识别会整道认错

我把「红烧萝卜丝（少量肉丝和葱）」认成「炒土豆片＋肉片」。他一句「第三个是红烧萝卜丝」纠正。

**影响量级参考**：土豆 81 kcal/100g vs 白萝卜 16 kcal/100g，同重量差 5 倍；碳水差 4.5 倍。
→ **素菜的「块/丝/片」形态最容易认错**（土豆丝/萝卜丝/粉条/笋丝在照片里几乎同构），
  认不准时在清单里**给出「可能是 A 也可能是 B」并说明差多少**，让他一句话定，比赌一个强。

## 外卖预演评估（「打算吃」阶段）

用户发点餐界面截图说「正在考虑点这个……帮我判断是否适配今天的营养摄入需求」。
**这是预演，不是记录。**

### 铁律

- 🔴 **只出评估，不落盘**。`~/health/diet/` 一个字都不许加。他当面纠正过「打算吃 ≠ 已吃」。
- 措辞用条件式：「如果点这单」「假设吃下」。
- 评估要**围绕他今天真实的缺口/超项**讲，不要泛泛说「均衡」。实测那天：脂肪已 125.5%、钠 75.8%、嘌呤 154.9%，
  而**蛋白只到 42.5%**——蛋白才是唯一能补的，脂肪/钠/嘌呤全是已经透支的。

### 外卖重油档（别用生鲜清炒值直接套）

| 菜 | 坑 | 档位 |
|---|---|---|
| 番茄炒蛋 | 外卖普遍 **15–25 g 油/份**，且**常加糖** | 给 10 g / 20 g 两档油，标明差多少卡 |
| 蒜蓉粉丝虾 | **粉丝吸油**，蒜蓉要用油浸；粉丝干重 vs 熟重差 3 倍 | **按干重记**；「只吃虾不喝汁」是独立一档 |
| 鲜烫菠菜 | 「烫」和「油淋/蒜蓉拌」差一个油档 | 先确认做法再定档 |
| 白米饭 | 外卖一碗 150–200 g，不是 90 g | 给区间，别按他家小碗的值 |

### 微调档要具体到「这份订单能改什么」

按影响大小排序，每档标出省下/增加多少卡、多少钠：
- 米饭减半 / 换少饭
- 番茄炒蛋备注「少油少糖」
- 粉丝只吃虾不喝底油汁
- 菠菜备注「不要油淋」

**不要写「多吃蔬菜」「注意控油」这种空话**——他会直接判定为没用的建议。

## 验收口径（本轮实测通过的做法）

派活前后各做一次独立复核，且**用它自证条目真实性**：

```python
from boohee import public_detail
r = public_detail(code)          # 免费，不耗额度
f = r[0] if isinstance(r, tuple) else r   # ⚠️ 返回是 tuple，直接 f.get 会 AttributeError
```

数值与健康助理报的完全一致，且拿到关键 units：

- 红烧鸡块 **1 个 = 75 g**
- 薄饼 `a5752ac5_c_259924`：**钠 920 mg/100g**（70 g = 644 mg，占午餐钠一半）、**钙字段为 None**（记「—」正确，不是 0）
