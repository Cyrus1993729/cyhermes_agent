# 合餐整鱼 / 鱼汤 / 外食估算口径（2026-11-05 定型）

> 场景：他报「三个人吃了一条身重三斤的黑鱼，我吃了可食部分的 40%」这类**共享主食 + 自估比例**。
> 这类数一定不能直接乘——先把「毛重→可食部→他的份额」三步写给他看。

## 一、毛重 → 可食部 → 份额（三步必须分开写）

```
毛重 1500 g（= 三斤）
  × 可食部率（表1-2「乌鳢（黑鱼、乌鱼、生鱼）」= 57%）
  = 855 g 可食部
  × 他自估的 40%
  = 342 g 鱼肉
```

**铁律**：
1. 「可食部率」**必须从表1-2 取**，不要拍脑袋。黑鱼 57%；带骨类参照 `bone-in-and-caliber-carryover-2026-10-23.md`。
2. **三步分开列出**，不要写一个总乘式。他要能看出 40% 是怎么落到克数上的。
3. **餐厅出肉率普遍低于成分表通用值**——鱼头、鱼骨、鱼皮进了汤锅不进盘。保守档可以把可食部率下修到 50%，并说明理由。
4. 同时给**保守 / 主值 / 宽松**三档（份额 ±5pp、出肉率 ±7pp），让他选，不要只给一个数。

## 二、鱼汤 = 嘌呤与钠的双重陷阱（重点）

表1-2 **没有鱼汤、也没有酸菜鱼汤条目**（只有牛肉汤 70、牛骨汤火锅前/后 4/53）。只能推算，**且必须明说「推算，非实测，误差可能 2 倍」**。

**钠**：按盐度反推，`1 g 盐 ≈ 393 mg 钠`。

| 盐度档 | 250 ml 一碗 | 适用 |
|---|---:|---|
| 0.4%（淡） | ≈393 mg（取 400） | 保守档 |
| 0.6%（中值） | ≈589 mg（取 600） | **主值** |
| 0.9%（咸） | ≈884 mg（取 900） | 宽松档 |

**嘌呤**：嘌呤易溶于水，久煮鱼汤 > 畜肉汤（牛骨汤熬后实测 53 mg/100g），高嘌呤鱼类长时炖煮可达 **500 mg/100ml 量级的上界**。实操取 **100 / 120 / 150 mg/100ml** 作保守/主值/宽松。

> ⚠️ 表1-2 只有「黑鱼 169」「黑鱼(熟) 214」，没有汤。它算出来的「一碗 ≈300 mg」是**推算值**，交付时必须带 ‡ 标记。

## 三、酸菜鱼整道菜拆项清单（缺项就漏算）

| 组成 | 何时要单列 | 典型量 |
|---|---|---|
| 鱼肉 | 必列 | 见上三步 |
| **鱼片挂油** | 必列——易漏 | 6–12 g，按食用油 899 kcal/100g |
| 酸菜 | 必列 | 25–60 g，表1-2「酸白菜」钠表未收录，按腌菜典型值推算（≈1125 mg/100g） |
| 酸汤 | 必列（按碗数给两档） | 见上 |
| 米饭 | 必列 | 碗重按档案惯用值（他 150 g） |

## 四、外食小食按「参照物」估重

小春卷 4 个（每个约食指长 5–6 cm）：单重 15–20 g，用表1-2「春卷」462/6.1/33.7/34.8（**油炸口径**，别用生春卷）。

→ 遇到「食指长」「拳头大」这类参照物描述：
1. 先给单重区间 + 依据（表1-2 同类炸物）；
2. 并明确问一句能提高精度的区分：**「超市冷冻那种还是饭店现炸的？」**——这类问题他凭常识就能答，符合他的确认边界。
3. 个数不确定（3 还是 4 个）→ 两档都给。

## 五、交付形状（他很在意）

- **三档对比表**：保守 / 主值 / 宽松，每档给晚餐合计 + 全天合计；末尾必须有一句「**两档真正的差别在哪一项**」（本次：差距主要不在热量，在钠和嘌呤——即「汤喝了几碗」）。
- **红黄绿三色标注**：按 profile.md 目标逐项标超限；超了就写「已超 N」。
- **置信度分级写进档案**：A 实测 / B 官方数据直取 / C 原料推算。
  整道外食菜大概率是 **C 档**，**落盘后仍要保留 C 档标注**，不要因为“已经存了”就当成实测数。
- 钠/钙字段表里未收录时记 **「†（未收录）」或「—」**，**绝不记 0**——0 会被当成实测零算进合计。

## 六、验收提示

他确认后只说一句「走主值档存盘」时：
- 把**选定档的逐项参数写成表格原样回传**给他看（鱼 342 / 挂油 9 / 酸菜 40 / 汤 250ml 一碗 / 饭 150 / 春卷 4×18）；
- 特别强调**「汤 1 碗」不要含糊成「1~2 碗」**——汤是钠和嘌呤的最大变量，不能留区间；
- 写完从磁盘读回验算，并报字节数 + 每餐行数一致性。
