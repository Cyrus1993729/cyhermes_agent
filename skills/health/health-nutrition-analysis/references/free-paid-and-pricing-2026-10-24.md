## 1. 免费 `public_detail` vs 付费 `detail()` 逐字段对撞

同一批食物三样，付费各 1 次，共 **3 次额度**（`quota.json` → `"2026-10-24": 3`）。

| 字段 | 免费口径 | 付费口径 | 判定 |
|---|---:|---:|---|
| 热量/蛋白/脂肪/碳水/纤维/钙（糯玉米 150g） | 250.5 / 5.85 / 3.30 / 49.35 / 1.80 / 27.0 | 完全相同 | 一致 |
| 钠（糯玉米） | 空串 → 借成分表 1.7mg | `"0.0"` | 付费的 0 = 未收录 |
| 嘌呤 | 表1-2 推算 18.0 | **三样全 `0.0`** | 付费不可用 |
| 糖 | 无此字段 | 牛奶 **0**（实际乳糖约 10.1g/206g） | 付费不可用 |
| 胆固醇 | 无此字段 | 茶叶蛋 **0**（1 枚约 290mg） | 付费不可用 |
| **饱和脂肪** | 无此字段 | 牛奶 4.33 + 蛋 1.55 = **5.88g** | ✅ 唯一可用 |

**结论：三大营养素零差异（本就是同一套库）；付费新增的 4 项里 3 项是假数。**
**为饱和脂肪付费可以，为嘌呤/糖/胆固醇付费不值。**
早餐 454.9 kcal 时 SFA 5.88g = 全天上限（22.2g）的 26.5%、供能占比 2.6%。

⚠️ 严格说只有糯玉米是真对撞（现查）；牛奶 `fdf1e8ef`、茶叶蛋 `fddb62ac` 的「免费口径」本来就是以前付费查下来的缓存，两边一致是必然的。

## 4. 虾类比价：折到可食部才可比

| | 黑虎虾 | 罗氏虾 |
|---|---:|---:|
| 页面（同平台、同为鲜活） | 300g / 8-12只 / ¥38.61 | 350g / 10-17只 / ¥39.90 |
| 折毛重 | 64.35 元/斤 | **57.00 元/斤** |
| 出肉率 | 55%（薄荷 units 33÷60）／59%（成分表斑节对虾） | 38%（30.4÷80）／40% |
| 可食 | 165g / 177g | 133g / 140g |
| **折虾肉** | **109.1–117.0 元/斤** | **142.5–150.0 元/斤** |

毛重上黑虎贵 12.9%，虾肉上便宜 22.0–23.5%。单只：黑虎 25.0–37.5g，罗氏 20.6–35.0g。
水分 黑虎 73.6% vs 罗氏 78.0%（「更紧实」的可查解释）；但**蛋白反而是罗氏高**（20.6 vs 18.6），
两条数据碳水口径不一致，不宜拿来下结论。

⚠️ 上一轮用「塘口批发罗氏 33 元/斤」对「进口冻品黑虎 49 元/斤」得出「折虾肉持平」——换同平台两张图后结论翻转。**跨渠道不可比。**

## 5. 火锅锅底（不喝汤前提）

每涮 100g 食材多带走：脂肪 辣 2–5g（冻豆腐/油豆皮 8–15g）vs 番茄 0.5–2g；
钠 50–150 vs 30–100 mg；糖 辣 0.3–1g vs 番茄 **1–3g**。
底料本身：牛油 471–718 kcal/100g、番茄 108–331（品牌差 2–3 倍，**底料值 ≠ 摄入值**）。
吸油排序：冻豆腐/油豆皮/宽粉/方便面 > 叶菜（3–5 倍）。**避开这四样比换锅有用。**
