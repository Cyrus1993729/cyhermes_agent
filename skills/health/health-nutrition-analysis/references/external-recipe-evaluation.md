# 外部食谱评估实战：一条 29 秒小红书视频 → 完整配方 → 健康判断

> 2026-10-19 实踩。他用一句「你帮我看看这个适不适合我」就丢来一个减脂食谱链接。
> 这个任务的难点**不在营养学**，而在「从一段视频里把配方挖干净」和
> 「识别博主自己报的数字为什么不能用」。

## 一、产出结构（下次照这个框子填）

```
① 配方还原（食材 / 克数 / 步骤 / 调料）  ← 从视频挖
② 博主自报营养卡                      ← 从画面挖
③ 两套数：博主口径 vs 实际口径           ← 你自己算
④ 健康判断（三大营养素 + 嘌呤 + 适不适合）← 结合他的指标
```

**①②是取证，③④才是他要的。但取证不干净，③④全是沙上建塔。**

## 二、那条帖子的实际数据（可作样本参考）

**「瘦子炒饭｜只有346大卡！菜心牛肉炒饭🥬」**
- noteId `6a0470ba0000000038037979`，视频 29 秒，720×1280，**带烧录字幕**
- desc 全是话题标签（134 字，零实质内容）→ 必须下载视频

**博主营养卡（视频第 2 帧，薄荷类 App 截图）**：

| 项目 | 值 |
|---|---:|
| 总热量 | 346 kcal |
| 蛋白质 | 34.4 g（39%） |
| 脂肪 | 4.3 g（11%） |
| 碳水 | 44.6 g（50%） |

食材 4 样共 465.7g：菜心 168g / 牛肉(精瘦) 115g / 藜麦饭 133g / 白蘑菇(鲜) 49.7g

自检：168+115+133+49.7 = **465.7** ✅；47+130+154+14 = **345** ≈ 346 ✅
热量回算：34.4×4 + 4.3×9 + 44.6×4 = **354.7** vs 346 → **+2.5%**（可接受）

**做法（按字幕顺序）**：牛肉切丁 → 生抽/老抽/黑胡椒/蚝油腌 → 口蘑切片 →
少许橄榄油 → 牛肉炒变色盛起 → 口蘑+菜心**梗**先下 → 再加**菜叶** → 少许盐+鸡精 →
倒回牛肉 + 130g 藜麦饭 → 出锅

## 三、核心发现：*346 kcal 是假的*

营养卡**只列 4 样食材，油和调料一个都没算**。而视频里在倒橄榄油、
用四种酱料腌肉、加鸡精。

| 补什么 | 加多少 | 依据 |
|---|---:|---|
| 橄榄油「少许」 | +45~90 kcal / +5~10g 脂肪 | 按 5–10g，无实测 |
| 蚝油（含糖） | +5~20 kcal | 量未知 |
| 生抽/老抽/鸡精 | 钠为主，热量可忽略 | 量未知 |

→ **实际 400–450 kcal，脂肪 9–14g —— 是卡片上的 2 倍还多。**

**推广到所有食谱帖**：博主贴的「只有 XXX 大卡」几乎都是**只算主料**的口径。
想拿它做减脂规划，**必须自己把油和调料加回去**。

## 四、调料量「博主没说」的实证

他明确要求「**包括他调料加了多少**」。逐帧核过：

| 来源 | 结果 |
|---|---|
| 口播 ASR | 「腌制一下」「少许的橄榄油」「少许的盐和鸡精」——零数字 |
| 画面字幕 | 同样措辞，零数字 |
| 营养卡 | 4 样食材，**油和调料全部不在** |
| 19 帧逐帧视觉 | 无任何调料克数标注 |

**结论：不是没找到，是博主没给。** 报告里就这么写，然后给估算区间并标明估算。

## 五、那次踩到的具体坑

### ① 口播和卡片数字不一致 → 以卡片为准

「120克牛肉」vs 卡片「115克」；「130克藜麦饭」vs 卡片「133克」。
**卡片是称过的，口播是顺嘴说的。**

### ② ASR 同音错字——必须靠画面校正

```
ASR 听成             实际
口膜                 口蘑
泥麦饭               藜麦饭      ← 靠营养卡帧和锅内画面确认
煎至鸡体多汁          煎至焦香多汁
十分钟来人继续炒饭     十分钟减脂炒饭
菜心鲜小             菜心洗好
```

**中文口播的 ASR 同音错是常态**，尤其食材名。**营养卡帧是最可靠的校正锚点。**

### ③ 封面文字和标题可能不一致

标题写「**菜心**牛肉炒饭」，封面写「**卷心菜**牛肉炒饭」，
而营养卡和锅内画面确认是**菜心**（168g）。

**判据：营养卡 > 画面实物 > 标题 > 封面。** 封面是运营做的，标题和卡片才是作者本人写的。

## 五点五、取证技术：字幕和画面数字怎么挖（踩过坑才定型的）

### 🔴 铁律：字幕必须**逐帧扫**，不能抽查（本次真翻车）

我抽了 f_004、f_008 两帧用 Vision 看，**都说「画面无任何文字」**，
于是差点下结论「视频没有文字标注」——**错了**。
扫完其余帧才发现，**全片每一句口播都配了烧录字幕**，包括关键的那条
「倒入牛肉和 130 克的藜麦饭」。

**字幕是逐句出现的，抽到没字幕的那帧概率很高。** 抽 2–3 帧就断言「无字幕」= 赌。

**正确做法**：写循环跑全部帧，**每帧只问一件事**：

> 「**只看画面底部的中文字幕**（白色带阴影的字），逐字读出来。没有就回"无字幕"。」

⚠️ **提问必须限定在字幕。** 问「读出所有文字」时，Vision 容易被画面主体带走，
跑去描述锅碗瓢盆，反而漏掉底部那行字。

### 🔴 数字密集的画面必须**原尺寸抽帧**（缩放帧读不全）

抽帧时如果带了 `scale=720:-1`，**营养卡这类小字会糊到读不出**。
本次先读成「米饭 133g = 14 kcal」（实际 154），就是缩放帧的锅。

```bash
# ␑ 粗扫用缩放帧（便宜，定位用）
ffmpeg -i video.mp4 -vf "fps=1/1.5,scale=720:-1" frames/f_%03d.jpg

# ✅ 发现关键帧后，按时间点抽**原尺寸单帧**精读
ffmpeg -y -ss 2.8 -i video.mp4 -frames:v 1 -q:v 2 ncard.jpg
```

**帧序号 → 时间点换算**（`fps=1/1.5` 抽帧时）：`t = (N-1) / fps`
→ f_001=0s、f_002=1.5s、f_003=3.0s…

**流程：缩放帧粗扫定位 → 算时间点 → `-ss` 抽原尺寸帧精读。**

### 三种文字来源的优先级

| 优先级 | 来源 | 怎么拿 | 特点 |
|:--:|:---|:---|:---|
| **1** | **烧录字幕** | 抽帧 → Vision 逐帧读底部 | **精确到字**，作者手写，**不会转错** |
| 2 | 画面信息（营养卡/UI） | 原尺寸抽帧 → Vision | 数字密集，必须原尺寸 |
| 3 | ASR | whisper | 覆盖最全但**同音错字是常态**（见上节） |

**字幕与 ASR 冲突时，以字幕为准。** 上面的「口膜/口蘑」等错字，用字幕能直接定案。

### 工具路径（Windows）

```bash
# ffmpeg 不在 PATH 时，imageio-ffmpeg 自带一个：
python -c "import imageio_ffmpeg; print(imageio_ffmpeg.get_ffmpeg_exe())"
# 若报 ModuleNotFoundError，装它：
uv pip install imageio-ffmpeg
```

`rapidocr_onnxruntime` 未装时**直接走 Vision 逐帧读**——
对字幕/营养卡这类结构化文字，**Vision 比 OCR 更准**，OCR 只是省钱选项。

## 六、最终该答什么

他会问「**健不健康 / 适不适合我**」，这个必须是**具体的**：

✅ 值得肯定：
- 藜麦饭替白米饭（低 GI，对他 HbA1c 6.3% 有利）
- 蔬菜总量 218g（菜心 168 + 口蘑 49.7），够量
- 牛肉选精瘦部位
- 结构上蛋白 39% 偏高、脂肪 11% 偏低，对减脂有利

⚠️ 要提醒：
- **蚝油含糖**（他 TG 3.27 偏高）
- 生抽老抽带钠（他舒张压压着 90）
- 油没算进卡里，真实脂肪翻倍
- 牛肉 115g 的嘌呤要单独算（他尿酸 454）

🔴 必须落到「实际执行」：
- 这碗当晚饭**量够不够**
- 跟他同一天的午餐（食堂高油高嘌呤）比是**好还是差**
