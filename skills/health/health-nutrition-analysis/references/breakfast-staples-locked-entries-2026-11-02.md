## 四、验收方法：它报的「薄荷·缓存 xxx」要先自证

1. **code 回查历史档案**：它给的 code 在本次 cache.json 里可能根本没有（`lanmei` 就不在），
   但可能在**更早的日记档案里有落档记录**（10-23 第 118 行）。先 grep 档案再判真假，
   别因为本地缓存里没有就当成编的。
2. 🔴 **字面中文 pattern 的 grep 可能假阴性**：本次 `search_files` 对「蓝莓」「希腊酸奶」
   在明确含该词的文件上返回 **0 处**，改用 Python `re` 扫同一批文件找到 55 处 / 1 处。
   → 中文关键词 grep 出 0 时，**用 `re` 复核一遍再下「没有」的结论**。
3. **四行加法自己重算**：逐项算 → 合计 → `蛋白×4+碳水×4+脂肪×9` 对比热量。
   本次复算 324.80 / 19.73 / 7.50 / 45.59 / 227.84 / 371.35，与它报的对得上。
4. `verify_diet_tables.py --strict` 会把「—」判成「不是数值」，报 1/N 行异常。
   **这是预期的**——包装标签没给纤维就必须写「—」不能写 0，别为了过校验改数据。

## 五、🔴 刚切燕麦纤维锁定值与出处（2026-11-05 用户明确要求）

用户原话：「钢切燕麦的纤维含量改一下，以便以后直接调用正确的」。
**以后碰到「刚切/钢切燕麦」，纤维直接拿 11.95 g/100g（干重），不要再推一遍。**

来源：USDA FoodData Central **`2346397`**「Oats, whole grain, steel cut」，Foundation，2022-10-28，
`Total dietary fiber (AOAC 2011.25) = 11.95 g/100g`。

为什么锁这条：
1. 条目名就是 steel-cut（钢切/刚切），**干重口径**，不折生熟
2. 该记录 **protein 12.511** 与薄荷 `fdac0fed` 的 **12.5** 逐位吻合 → 两者同源，用它补缺口最自洽
3. AOAC 2011.25 含低分子量纤维（LMWDF 0.7024），口径比老法完整

同一记录的其它值（需要时直接用，别再查）：
能量 379.2 kcal（Atwater 特定系数）/ 381.2（通用）｜蛋白 12.51｜脂肪 5.8｜碳水 69.75｜
纤维 11.95（HMWDF 11.21 + LMWDF 0.70，β-葡聚糖 5.44）｜钙 51.34｜钠 0.31｜镁 128.6｜磷 417.3｜钾 375.9｜铁 3.80

❌ **别再用的三个值**：
- 表1-2「燕麦」`019012`（青海）**6.0** —— 老法、非钢切口径，**低估近一半**（11-05 就是错在这里）
- USDA SR Legacy 快熟燕麦干重 **10.6**、Bob's Red Mill 10.6 —— 老 AOAC 991.43 口径
- 中国疾控「燕麦片」`OFFICIAL-1286` **13.2** —— 是燕麦片，不是钢切

真实区间 10.6–13.2，锁定 **11.95**。

⚠️ **纤维不产能**：改纤维**不改热量**、不改蛋白/脂肪/碳水，`4P+4C+9F` 自洽校验也不受影响。
