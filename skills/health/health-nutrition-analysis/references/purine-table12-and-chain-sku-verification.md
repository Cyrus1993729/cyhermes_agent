## 三、连锁餐厅 SKU 核验 —— 两条铁律

### 铁律 1：按 `code` 核，不要按名字核

`public_units(名字)` 按匹配分返回，会命中**同名但不同规格**的条目。实测：
```
搜「西兰花炒鸡胸肉」→ 「西兰花炒鸡胸肉(少油少盐)」300g / 70 卡（匹配分 92）  ← 错的那个
真正要的             → 「老乡鸡 西兰花炒鸡胸肉」40a9eac71786006001  220g / 94 卡（100 分）
```
→ **先用历史档案里的 code 直查，或搜「品牌名 + 菜名」。** 名字匹配通过不等于条目对了。

### 铁律 2：用同品牌「兄弟 SKU」做差分，抠出单一食材的贡献

同店同菜、只差一个配料的两个 SKU 相减：

```
老乡鸡 清炒毛白菜  e77afd4f1786006002   89 kcal｜蛋白 1.7｜脂肪 8.8 ｜碳水 1.0｜钠 398
老乡鸡 豆皮毛白菜  e55aa0bc1786006004  113 kcal｜蛋白 2.8｜脂肪 10.7｜碳水 1.7｜钠 445
差分                                    +24       +1.1      +1.9       +0.7      +47
```
再拿《中国食物成分表》千张（蛋白 24.5／脂肪 16.0，`fooddb/foods.json` 可直接查）反推：
豆皮 ≈ **4.5 g/100g**（整份约 9 g），只解释 0.72 g 脂肪。
→ 这个差分还能反证嘌呤拆分：豆皮 9g×89 + 毛白菜 191g×14 = 34.7，与原记 35.75 只差 1。

## 四、🔴 归因陷阱：不要凭品类常识断定「脂肪来自哪个食材」

2026-10-30 犯过：看到「豆皮毛白菜 21.4 g 脂肪」就写「**豆皮是油炸豆制品**，是这道菜的脂肪来源」。
**错。** 差分显示：

```
豆皮本身    ≈ 3.5 g（16%）
餐厅炒菜用油 ≈ 17.9 g（84%）
```

因为那位**没有豆皮的纯素版**（清炒毛白菜）脂肪就已经 **8.8 g/100g**。

→ **单食材归因必须做差分验证**，否则连着给出的「明天怎么改」会一起指错方向。
→ 反过来差分也给出更好的抓手：同店「**烫青菜**」41 卡 / 脂肪 3.4/100g ——
  同样是素菜，做法一换脂肪差 **2.6 倍**，比「豆制品换水豆腐」有力得多。

## 七、验收清单（每次派活后照着走）

1. 回 `fooddb/boohee_api/cache.json`，按 **code** 对每 100g 值
2. 调 `public_units` 复核「1 份 = 多少克」（按品牌名搜，不按裸菜名）
3. 自己按 `per100g × 克数` 重算全部列，**不采信它给的合计**
4. 跑 `scripts/verify_diet_tables.py <档案>`，确认表没坏
5. 与历史同类项横向对账（同项目、同时长、同 MET 档应逐位复现）
