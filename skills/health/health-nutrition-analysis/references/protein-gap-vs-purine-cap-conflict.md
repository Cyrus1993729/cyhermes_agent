# 蛋白缺口 vs 嘌呤天花板：冲突时的解法顺序

该用户尿酸 454（药物门槛 480，差 26），同时目标是减脂增肌（每次核查都要对照 profile.md 的蛋白目标）。
这两个约束会周期性撞车，且**默认解法（吃肉补蛋白）正好是错误解法**。

## 冲突长什么样（2026-11-06 实例）

一天到午饭结束时：

| 项 | 状态 |
|---|---|
| 蛋白 46.67 / 129 | **差 82.33 g**（最大的缺口） |
| 热量 947.81 / 2075 | 差 1127（缺口很大） |
| 纤维 4.35 / 25–30 | 差 20+ |
| **嘌呤 258.16 / 300** | **只剩 41.84** |

四个数字同时成立 → **常规解法全被堵死**：想补 82 g 蛋白就得吃一大块肉，而那一下就吃掉 42 mg 嘌呤额度。

## 解法优先级（按嘌呤成本从低到高）

1. **蛋（蛋清为佳）** —— 嘌呤极低（鸡蛋 ~1 mg/100g 量级），蛋白密度最高的低嘌呤项。
2. **奶/无糖酸奶** —— 全脂纯牛奶（家里固定品种）、嘌呤 ~2 mg/100g；既补蛋白又补钙。
   （注意：**一律按全脂算**，不要拿脱脂条目或建议脱脂。）
3. **大豆制品要小心，不是纯解** —— 豆腐/豆干/腐竹嘌呤中等偏高，豆干、腐竹尤其不低。
   “豆制品补蛋白”在这个用户身上**不能当成无脑推荐**，要看当天剩余额度。
4. **鸡胸/瘦牛肉等瘦肉** —— 嘌呤中等，能吃但一顿只能小份。
5. **海鲜、浓汤、内脏** —— 基本封杀。鱼汤、酸菜鱼汤、火锅汤是嘌呤浓度最高的形态，
   嘌呤易溶于水、久煮浓缩，一碗汤的嘌呤可以超过一份肉。

## 交付时必须做的两件事

1. **明说“这不是多吃少的问题”**：当热量缺口大但嘌呤快满时，用户最可能的错误反应是“那我多吃点”。
   要直接告诉他：**缺的热量不能靠肉补，只能靠低嘌呤高能量密度的东西（奶、蛋、主食、部分坚果）**。
2. **不要把“蛋白达标”当作唯一目标去推荐肉类**：用户已经当面纠正过一次
   「点名「主要判断 X」后，只按 X 论证」——若他这顿问的是嘌呤，就别拿蛋白缺口当理由推肉。
