# 嘌呤全靠表1-2 · 本地资产、否证清单、差分校验法

> 2026-10-30 全天核查实战沉淀。当天 16 个含嘌呤条目里 **7 项明显错误**（4 项填 0、1 项只算了蛋、2 项整节没记），
> 全天 118.0 mg → 修正后 247.18 mg，**低估 2.1 倍**。错的全来自「采信薄荷 `purine` 字段」。

## 一、权威源与本地资产

| 项 | 内容 |
|:--|:--|
| 权威源 | 《成人高尿酸血症与痛风食养指南（2024年版）》附录1 **表1-2**（国家卫健委官网 PDF，2024-02） |
| 本地表 | `~/health/fooddb/purine_table12.json` —— 14 个类目 **398 条**，每类 `{食物名: mg/100g}` |
| 别名表 | 同文件 `_ALIAS` 键，**139 条** `{别名: {table, factor, note}}` |
| 用法 | 先查 `_ALIAS` 换名（带 `factor` 折算），命不中再查表体；都没有 → 写「未覆盖」，**不许写 0** |

**别名表是这步能跑起来的关键**：按表体原名精确匹配，一天 12 个条目只能命中 3 个（菜名/俗称对不上）。
加 `_ALIAS` 后命中 11/12。`factor` 专门处理折算类：`米饭 → 大米 × 0.4`、`粥 → 大米 × 0.25`。

## 二、🔴 表1-2 里没有的东西（否证清单，别再去找）

已逐项 grep 原文确认 **不存在**：`米饭(蒸)`、`韭菜`、`韭黄`、`小白菜/青菜/上海青`、`蓝莓`、`液态奶/牛奶/酸奶`。

- **米饭(蒸) 18 mg/100g 是个历史误标**：表1-2 谷物类只有「大米 44」「粳米 31」（都是**生米**值）。
  18 = 44 × 0.4（生米→熟饭重量比），**数对、出处错**。历史档案写成「表1-2 直接查表」是归错了出处，不用回修数据，改脚注即可。
- 液态奶/酸奶 → 按乳类（第四类 <30）推 **2 mg/100mL**；蓝莓 → 水果类推 **10 mg/100g**；
  韭黄/韭菜 → 借葱蒜类「大葱 31」，**必须给区间 21–38**；青菜 → 借「油菜 17」。

## 三、🔴 两个反直觉值（串档会直接判错）

1. **菠菜只有 8 mg/100g。** 民间「菠菜是高嘌呤蔬菜」用的是别的表口径（日本表约 57）。
   → 按表1-2 口径，**菠菜不构成嘌呤来源**。见过一次误判，差点把它记成 88 mg。
2. **鸡胸 208 是所有肉里最高**，比牛肉 105 高一倍、比猪肉 138 还高。
   → 「不吃牛肉改吃鸡胸」在嘌呤上是**反向操作**（这条与尿酸策略节「瘦牛肉单位蛋白嘌呤最低」是同一结论的两面）。

## 四、薄荷 `purine` 字段的三种坏法（都要拦）

| 坏法 | 例（2026-10-30 实测） | 拦法 |
|:--|:--|:--|
| 菜品级恒填 `0.0` | 米饭 0、青菜 0、生抽 0、牛肉片 0 | 一律不采信 |
| 填近 0（只算了主料） | 韭黄炒蛋 **0.6**（只反映鸡蛋 1 mg/100g，整份蔬菜没算） | 值 ≥0 但 < 同餐数量级 → 查表 |
| 整节缺列 | 加餐三道原料**根本没有嘌呤列** | 表头必须带嘌呤列 |

**判据**：`purine == 0` 或 `purine/100g < 3` 时，一律视为未收录，改走表1-2。

## 五、🔴 兄弟 SKU 差分法（品牌菜必用，2026-10-30 豆皮毛白菜实战）

同品牌两条 SKU 只差一个配料时，**做差分能把这个配料的贡献单独隔离出来**，比按原料拼的推算硬得多。

```
老乡鸡 清炒毛白菜  e77afd4f…  89 卡 ｜蛋白 1.7 ｜脂肪 8.8 ｜钠 398 ｜1份=190g
老乡鸡 豆皮毛白菜  e55aa0bc… 113 卡 ｜蛋白 2.8 ｜脂肪 10.7｜钠 445 ｜1份=200g
差分                        +24    +1.1      +1.9      +47
```

用《中国食物成分表》千张（蛋白 24.5 / 脂肪 16.0）反推：豆皮≈4.5 g/100g（整份≈9 g），
**只解释 0.72 g 脂肪**，其余 1.18 g/100g 是额外用油。
→ 整份 21.4 g 脂肪里，豆皮本身 ≈3.5 g（16%）、**餐厅炒菜油 ≈17.9 g（84%）**。

**结论修正**：先前口径把「豆皮毛白菜脂肪高」归因给「豆皮是油炸豆制品」——**错**。
真正的原因是连锁店炒菜油重（**没有豆皮的白灼青菜也有 8.8 g 脂肪/100g**）。

**可迁移的两条**：
1. 品牌菜脂肪/钠异常时，先找**同店同类但少一个配料**的 SKU 做差分，别急着怪食材。
2. 给调整建议前先查同店**做法更低脂的对应项**：老乡鸡「烫青菜」41 卡 / 脂肪 3.4，对比「清炒毛白菜」89 卡 / 8.8 ——
   同样是素菜，**换个做法脂肪差 2.6 倍**，这比「换食材」的杠杆大得多。
