## 三、🔴 最大教训：一份输出里三套数字

第一版健康助理输出：

```
开头结论行：  ~790 卡 ｜ 56 蛋 ｜ 53 脂 ｜ 25 碳 ｜ ~1980 钠 ｜ ~396 嘌 ｜ ~4 纤
表格尾的合计：  ~786 卡 ｜ 65.8 蛋 ｜ 89.5 脂 ｜ 52.8 碳 ｜ ~2380 钠 ｜ ~580 嘌 ｜ 2.6 纤
11 行逐行相加： 1286 卡 ｜ 65.8 蛋 ｜ 89.5 脂 ｜ 52.8 碳 ｜ 2480 钠 ｜ 580 嘌 ｜ 2.6 纤
```

- **热量差 500 卡**（786 vs 1286）
- **钠差 100mg**（2380 vs 2480）
- **蛋白/脂肪/碳水三列反而是对的** → 「对一列」不代表对

用 execute_code 独立复算才抓出来：

```
行相加: [1286, 65.8, 89.5, 52.8, 2480, 580, 2.6]
热量差 500 | 蛋白差 0.0 | 脂肪差 0.0 | 碳水差 0.0
```

### 重算任务书里加的硬约束

```
1. 表格行和 ≠ 合计行 → 已作废
2. 开头结论行是第三套数 → 同一份输出里出现三个版本，不可接受
3. 钠合计也对不上

→ 本轮每一列都必须现场加一遍并写出行和，
  合计行 = 行和，结论行 = 合计行，三处必须字面一致。
→ 数字必须先加后写，不许凭印象填合计。
```

重算后的输出带了一块「三处一致性自检」，把七列的行和算式全写出来，
并附交叉自检 `87.47×4 + 54.72×4 + 68.21×9 = 1182.6 vs 1183.9 → −0.1% ✓`。

**但注意：它第一版也写着「三处字面一致」。自报的 ✓ 不能当证据，必须自己复算。**

## 四、🔴 三个高热密度条目：复核结论各不相同

复核起因：花雕鸡 524 卡占了 786 的 2/3，明显不合理。

### ① 招牌花雕鸡 `huadiaoji` — ❌ 不可用

```
回查完整字段：calory 394 / protein 10.0 / fat 36.7 / carb 4.4 / fiber 0.1 / natrium 259.45
units：1 盘 = 300g（1183.14 卡/盘）
```

**内部算术是自洽的**（`10×4 + 4.4×4 + 36.7×9 = 387.9 ≈ 394`）→ 不是录入笔误，这条本身就是这样。

**但对不上鸡肉：**

| 来源 | 热量 | 蛋白 | 脂肪 |
|:--|--:|--:|--:|
| 成分表 `091101x` 鸡（代表值） | 145 | 20.3 | 6.7 |
| 成分表 `091301` 扒鸡（整鸡卤熟） | 217 | 29.6 | 11.0 |
| **薄荷 `huadiaoji`** | **394** | **10.0** | **36.7** |

**蛋白只有鸡肉的一半，脂肪是 3.3–5.5 倍，脂肪占重量 37%，接近五花肉水平。**
→ 这条代表的是**鸡皮 + 鸡油 + 浮油**，或另一道重油菜，不是花雕鸡本身。

**改用**：成分表 `091301 扒鸡`（整鸡熟制最近的一档）下调 10%（花雕鸡带汁、含水高于扒鸡），
再补花雕酒+糖 4g 碳水：
```
211 卡 / 26.6 蛋 / 9.9 脂 / 4.0 碳    ← 自检 26.6×4 + 4×4 + 9.9×9 = 211.5 ✓
```

### ② 手工春卷 `chunjuan` — ✅ 可用，465 是对的

逐位撞上成分表 `OFFICIAL-1199 春卷`：
```
462 卡 / 6.1 蛋 / 33.7 脂 / 34.8 碳 / 钠 485.8
```
**465 不是偏高，炸春卷就是这个数**（脂肪 33.7g/100g 已经是油炸后的）。
附带好处：**钠 485.8 是真实测量值**，这项不用估。单位 1 小个 = 30g / 139.5 卡。

### ③ 干炸臭豆腐 `fd5ec31d` — ⚠️ 是生的，干炸必须加油

成分表 `OFFICIAL-1546 腐乳(臭)[臭豆腐]` = **131 / 11.6 / 7.9 / 3.9** → 与薄荷 126 对得上，
确认这条是**未炸的生臭豆腐**。

⚠️ 它的 `units` 写「1 块 = 350g」是**整块发酵豆腐**（腐乳块那种），**不是他吃的干炸小块，这个 unit 不能用来数「2 块」**。

干炸吸油按 **12%**（炸豆制品 10–15% 中位）→ `126 + 12×9 = 234`：
```
234 卡 / 13.3 蛋 / 19.9 脂 / 3.4 碳
```
交叉验证：成分表「油豆腐」（炸豆腐）= 245 / 17.0 / 17.6 → 同量级 ✓

## 七、可复用清单

1. **预结单里的菜名是权威值**，但仍要逐字核（窄屏单据识别容易错一字）
2. **合菜按 1/N 平摊前先问「他能不能判断」**——自己一碟问克数，大圆桌用系数
3. **三档可改假设（系数 / 米饭 / 绝对量）永远单独列成可复制的纯文本**
4. **「整碟可食重」必须写出来**，否则 1/9 无从判断
5. **行和、合计行、结论行必须三处字面一致**，自己用代码复算，不信自报 ✓
6. **高热密度条目逐个复核**：脂肪占比 >30% 的禽类/鱼类菜条先当错条；油炸工艺的生料条目必须补吸油
7. **看不出是什么的项（「煲」）明写存疑不计入**
8. **他改口时以最后一版为准**，前面那版显式作废
