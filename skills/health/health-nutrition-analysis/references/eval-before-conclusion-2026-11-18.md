## 一、五条规则（下次直接照做）

### 规则 1：禁止跨指标比百分比

百分比消掉单位，**没消掉生理差别**。同一张「偏离目标百分比」排行榜把三种类型的指标混排，排序结果是假的。

**先把指标分三型**
```
下限型（未达＝缺口；超出通常是好事）  蛋白、钙、钾、纤维
上限型（超出＝负担；未达没问题）      钠、嘌呤、添加糖
区间型（两侧偏离都有意义）            脂肪供能比、碳水供能比／总量
```
**执行**
```
下限型 → 只写「还差 X」，不写「超出风险」，不参与超额排名
上限型 → 只写「已超 X」，不写「未达」，不说「差一点没超是好事」
区间型 → 两侧都报，用百分点
禁止   三型混排成百分比榜并宣布「第 1 远 / 第 2 远」
```
**反例（2026-11-18 我做的榜）**
```
嘌呤 +118.25%  ← 第1
脂肪  +26.58%  ← 第2
蛋白  −12.16%  ← 第3
纤维   +5.56%  ← 第4      ← 纤维超出通常是好事，在这里被当成"风险第四名"
钠     +4.88%  ← 第5
热量   +3.29%  ← 第6
碳水   −2.40%  ← 第7
```
这个榜把「下限型（蛋白、纤维）」「上限型（嘌呤、钠）」「区间型（脂肪、碳水）」三种完全不同的东西按同一把尺子排序，**结论必然错**。

### 规则 2：五条硬约束必须放在最前（缺一条，评估作废）

```
尿酸 UA    454 μmol/L   >420 高尿酸；离药物门槛 ≥480 只差 26（已有脂代谢异常＋超重两项合并症）
LDL-C      4.37 mmol/L  ≥4.1 升高
TG         3.27 mmol/L  ≥2.3 升高
TC         6.91 mmol/L  ≥6.2 升高
HDL-C      1.46 mmol/L  正常偏上（保护因素，说明脂代谢非全盘崩坏）
＋ 减重期预警：酮体与尿酸竞争同一肾小管排泄通道 → 第 1–4 周尿酸很可能不降反升
```
**为什么**：外部模型给的是「普通健康人」的通用结论；对他的尿酸 454、血脂三项升高，通用结论失效。**不带这五条，评估起点就错。**

**加权顺序（按他本人情况，不是按百分比）**
```
嘌呤 > 脂肪 > 钠 > 纤维/蛋白 > 热量 > 碳水
  · 嘌呤第一：尿酸 454 余量只剩 26，一次升 30 就跨药物门槛
  · 脂肪第二：TG 3.27 + LDL 4.37 + TC 6.91 三项升高，脂肪供能比与之同向
```

### 规则 3：归因对象必须对齐——增量 ≠ 存量

```
算「这顿的账」 → 只能用这顿的增量 Δ
写「全天偏差」 → 才能用全天存量
混用 = 把存量记到这一顿头上
```
**2026-11-18 的错**：这顿脂肪 +15.43 g（＝138.87 卡），我写成「全天超额 17.81 g（160.29 卡）」来论证这顿代价大——归因对象错位。

### 规则 4：「N 倍」必须带三件套

```
❌ 「脂肪超额扩大 7.5 倍」 —— 17.81 ÷ 2.38 ＝ 7.48，算术对；但基数只有 2.38 g，只给倍数＝制造印象
✅ 脂肪 69.38 → 84.81 g（+15.43 g）；供能比 34.61% → 36.95%（+2.34 个百分点）
```
规则：只要出现「倍」，同句必须有 原值 ＋ 差值绝对量 ＋（百分点或占比）中至少一项。

### 规则 5：不许用「它没做到本来不归它负责的事」当否决理由

```
加餐没有义务修复午晚餐留下的问题
单顿没有义务把全天嘌呤压到 300
一样食物没有义务同时满足所有指标
```
**2026-11-18 的错**：用「它没有改善全天嘌呤」支持「不划算」。比较对象错了——那顿嘌呤只 +6.36 mg（基本中性），**这恰恰是它作为补蛋白手段的优点**：补 17.97 g 蛋白，嘌呤代价几乎为零。

## 二、2026-11-18 完整案例复盘

### 输入
```
加餐2：酸奶 105 g ＋ 黑莓 40 g ＋ 蜂蜜 3 g ＋ 白煮蛋 ×2（可食 105.6 g）
= 261.69 卡｜蛋白 17.97｜脂肪 15.43｜碳水 13.47｜纤维 2.12｜钠 181.27｜钙 175.86｜嘌呤 6.36
当日已入档（吃这顿后）：2065.76 卡｜蛋白 113.32｜脂肪 84.81｜钠 2097.52｜嘌呤 654.74
不吃版本：1804.07 卡｜蛋白 95.35｜脂肪 69.38｜钠 1916.25｜嘌呤 648.38
目标：2000／129／67／220／25／2000／300
```

### 我当晚的四条结论 vs 复核

| 我的说法 | 判定 | 复核依据 |
|---|---|---|
| ①「补了蛋白」但把它排第三 | 数对，排序方法错 | 跨型比百分比；蛋白是下限型，只能谈「还差」 |
| ②「有热量赤字所以脂肪超得不算大事」 | 一半对一半错 | 赤字 431.99 里 346.50（80.2%）来自运动；不含运动只有 85.49 |
| ③「鸡蛋维生素挺多」 | 只能部分成立 | 库内只有 VA/VE/B1/B2/烟酸；VD/胆碱/B6/B12/叶酸 无字段 → 无法判定 |
| ④「钠嘌呤超得不多」 | 钠成立，嘌呤不成立 | 钠 +97.52（4.88%）；嘌呤 +354.74（2.18 倍），且这顿只贡献 6.36（1.0%） |
| ⑤「这顿不划算」 | **结论无依据** | 犯了规则 1/3/4/5，且完全没带五条硬约束 |

### 结论应该怎么说（按新口径重写示范）

```
这顿的账（只看增量）：
  换来  蛋白 +17.97 g（补掉缺口 33.65 的 53.4%）｜钙 +175.86 mg｜纤维 +2.12 g（越 25）
  付出  脂肪 +15.43 g ＝ 138.87 卡（供能比 34.61% → 36.95%，+2.34 个百分点）
        钠 +181.27 mg（其中蛋 138.86）
        热量 +261.69 卡
  中性  嘌呤 +6.36 mg（几乎为零，这是优点不是缺点）

放到他的硬约束下看（权重：嘌呤 > 脂肪 > 钠 > 纤维/蛋白）：
  · 嘌呤：这顿基本中性 → 不构成反对理由；今天 654.74（+354.74，2.18 倍）是午餐 338.00 ＋ 晚餐 247.20 造成的
  · 脂肪：+15.43 g 是唯一实打实的代价，且落在 TG 3.27 / LDL 4.37 / TC 6.91 三项升高的背景下
  · 钠：+181.27 mg 把全天从 1916.25 推过 2000（超 97.52，4.88%），幅度小
  · 蛋白：+17.97 g 是这顿唯一的净收益，且仍差 15.68 g 到 129

判断（带条件）：在「补蛋白」这一项上成立；在「脂肪」这一项上是明确的代价。
如果只能给一句话 → 「补蛋白效率高（17.97 g 换来嘌呤几乎为零），代价集中在脂肪 +15.43 g；
在 TG 3.27 的背景下这笔代价不是零成本，但也不是这顿饭独自造成的。」
```

### 这次暴露的三处方法病根

1. **贪图好排序**：跨型百分比榜好看、好交付，但它是伪排序。
2. **忘了他是谁**：评估写成了「对普通健康人的通用判断」，五条硬约束一条没带。
3. **拿存量当增量 + 拿倍数当量级**：结论被数字修辞推着走，不是被数据推着走。

## 三、交付前 30 秒自查（五问）

```
1. 我有没有把下限型（蛋白/钙/钾/纤维）和上限型（钠/嘌呤）的百分比放进同一张榜排序？
2. 五条硬约束（尿酸 454／LDL 4.37／TG 3.27／TC 6.91／HDL 1.46 ＋ 减重期尿酸预警）写进去了吗？
3. 每个偏差量：是这顿的增量，还是全天存量？有没有混用？
4. 每个「N 倍」旁边有没有原值＋绝对量＋百分点？
5. 我用来否决的理由，是不是它本来就不负责的事？
```

**任一条答「是」或「没有」→ 不许交付，重写。**
