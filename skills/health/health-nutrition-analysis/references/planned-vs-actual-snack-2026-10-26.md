# 计划加餐 → 实吃加餐的转换（2026-10-26 实战）

同一天内，加餐先以「计划」出现、后以「实物」落地，两版的差异把「计划≠已吃」这条铁律推到了极致。

## 1. 两版对比

| 项 | 计划版（他先说） | 实吃版（他回来说的） |
|:--|:--|:--|
| 酸奶 | 无糖酸奶 100g（BASIC 希腊） | **君岛/Larmilk 0 蔗糖希腊式 300g** |
| 水果 | 蓝莓 80g | **蓝莓 125g** |
| 蛋 | **茶叶蛋 1 个（50g）** | **没有吃** |
| 其他 | — | **蜂蜜 10g（计划里根本没有）** |
| 合计 | 179.2 卡 / 18.4 蛋 / 4.8 脂 / 17.2 碳 / 338.8 钠 / 10.5 嘌 | 291.0 卡 / 33.91 蛋 / 0.38 脂 / 39.87 碳 / 115.7 钠 / 18.6 嘌 / 3.0 纤 / 368.1 钙 |

他的原话：

> 「今晚如果吃不够 晚上我就再加一个无糖酸奶拌蓝莓&茶叶蛋」
> 「我回来吃加餐了，加餐用的是这款酸奶酸奶放了300克，另外放了125克的蓝莓以及10克的蜂蜜。」

## 2. 实吃版逐项（酸奶用包装标签值）

君岛 Oarmilk 0 蔗糖希腊式，每 100g：能量 264 kJ、蛋白 11.0 g、脂肪 0 g、碳水 4.5 g、糖 0 g、钠 38 mg、钙 120 mg。

```
酸奶 300g：264÷4.184 = 63.10 卡/100g × 3 = 189.3 卡｜33.00 蛋｜0 脂｜13.50 碳｜114.0 钠｜360.0 钙
蓝莓 125g：57 卡/100g（薄荷通用）        =  71.3 卡｜ 0.88 蛋｜0.38 脂｜18.13 碳｜  1.3 钠｜  7.5 钙
蜂蜜  10g：304 卡/100g（USDA）、碳水 82.4g/100g = 30.4 卡｜0.03 蛋｜0 脂｜ 8.24 碳｜  0.4 钠｜  0.6 钙
加餐合计                                    291.0 卡｜33.91 蛋｜0.38 脂｜39.87 碳｜115.7 钠｜368.1 钙
```

**交叉验证**：包装写「每杯 33g 蛋白」，11.0 × 3 = 33.0 → **300g 正好一杯**，与他报的 300g 互证。

## 3. 全天与赤字

```
三餐     1538.5 卡 83.58 蛋 57.79 脂 170.91 碳 3682.1 钠 604.6 嘌 17.00 纤
加餐      291.0 卡 33.91 蛋  0.38 脂  39.87 碳  115.7 钠  18.6 嘌  3.02 纤
全天合计 1829.5 卡 117.49 蛋 58.17 脂 210.78 碳 3797.8 钠 623.2 嘌 20.02 纤

TDEE 2575.8 − 摄入 1829.5 = 赤字 746.3 卡（29.0%）
蛋白 117.49 / 80.8 = 1.45 g/kg（目标 129g，达成 91.1%）
钠   3797.8 / 2000 = 190%
```

**不加这套加餐时赤字是 1037.3（40.3%）；加上后降到 746.3（29.0%）**，仍在 20–25% 之上但缺口小了一半。

## 4. 加餐的「蛋白效率」口径（他会关心的一列）

```
加餐  291.0 卡 ÷ 33.91g 蛋白 = 8.6 卡/克蛋白   ← 全天最优
早餐  350.1 ÷ 13.50         = 25.9
午餐  590.1 ÷ 35.30         = 16.7
晚餐  598.3 ÷ 34.78         = 17.2
```

一杯高蛋白希腊酸奶是全天的蛋白效率之王，**这条比单纯说「补了 34g 蛋白」有说服力**。

## 6. 两个数据坑

- **蜂蜜碳水 82.4，不是 75.9**：我第一版把 75.9 当成碳水（其实是糖的含量），USDA FoodData Central 给的是碳水 82.4g/100g、糖 82.1g/100g。10g 差 0.65g，量级小但属系统性低估。
- **酸奶 300g 不是 3 盒，是 1 杯**：这款没有标注每盒克数，靠「每杯 33g 蛋白」反推出 300g/杯。**看到「每杯 X 蛋白」优先反推份量，比猜盒数靠谱。**
