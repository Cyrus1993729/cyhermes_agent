# TDEE 与赤字口径：三档法（2026-10-29 定稿）

> 核心矛盾：PAL 1.25 已经隐含了日常零散走动。再叠加步行热量就是**重复计算**。
> 但也不能一律不算，否则走了 13000 步也当坐班。

## 基线

| 项 | 值 | 来源 |
|---|---:|---|
| 体重 | 80.8 kg | 用户自报体重秤 |
| BMR | **1759 kcal** | Mifflin-St Jeor |
| PAL（基线） | **1.25** | 久坐办公 |
| 基线 TDEE | **2198.8 kcal** | 1759 × 1.25 |
| 已覆盖走动 | ≈ 3000 步 | 日常零散，**不再单独计** |

## 三档口径（先定档，再算数）

### 档 A：无额外运动（正常坐班）

**直接用基线 TDEE，不做任何增量。**

```
TDEE = 1759 × 1.25 = 2198.8
```

🔴 **不要套「只计增量」公式**。那个公式是为步行日准备的，今天用了会算出莫名其妙的数。

**判定关键词**：用户说「正常上班」「没额外运动」「大部分时间坐着」「非常正常的一天」。

### 档 A′：休息档 PAL 1.20（生病 / 居家 / 卧床日，2026-11-02 首次采用）

```
TDEE = 1759 × 1.20 = 2110.8        （比档 A 低 88.00 kcal）
```

**触发条件（三个同时满足才降档）**：① 无运动；② 他**明确说**在休息/生病/卧床；③ 活动量明显低于坐班。
**默认仍用档 A 的 1.25**，只有在他说「按休息档算」「今天就躺着」这类话时才降到 1.20。

2026-11-02 实例（咽喉肿痛、原定当晚运动取消）：
> 他原话「**今天按照休息档来算，那个 pal 就按 1.2 来算**」
> TDEE 2110.8，摄入 2401.26 → 盈亏 **−290.46（盈余）**；同一天按 1.25 只有 −202.46，**差 88.00**。

🔴 **跨日对比时必须先声明口径变了**，否则 TDEE 不可直接比。落差要拆成两段：

```
盈亏差 = 多吃 + 少耗
10-29（PAL 1.25，摄入 1961.65，赤字 +237.1） vs 11-02（PAL 1.20，摄入 2401.26，盈余 −290.46）
527.56 = 439.61（多吃） + 87.95（TDEE 从 2198.8 降到 2110.8）
```

🔴 **不要把降档当成「今天消耗少所以没关系」的安慰**——降档只会让盈余更大，方向和他想听的相反。
写进档案时把「本日 PAL=1.20」写在口径声明表里，别只写在正文。

### 档 B：外出步行（没正式运动）

```
增量步数 = 总步数 − 3000        （3000 已被 PAL 覆盖）
距离     = 增量 × 0.68 m        （慢走步幅 0.65–0.72 取中值）
时长     = 距离 ÷ 4 km/h        （慢走速度）
净增     = (MET 3.0 − 1) × 体重 × 时长
TDEE     = 2198.8 + 净增
```

🔴 **全程用净增量 `(MET − 1)`，不是满额 `MET`。** 基线 PAL 1.25 已含静息，
满额会把静息再算一遍（35 分钟就多算 47.1 kcal）。下面档 C 同理。

敏感档：MET 2.8 / 3.0 / 3.5。
实测：13000 步 → 增量 10000 → 6.8 km → 1.70 h → **+274.7 kcal** → TDEE 2473.5（隐含 PAL 1.41）。

### 档 C：正式运动（羽毛球、力量训练等）

```
净增 = (MET − 1) × 体重 × 小时
TDEE = 2198.8 + 净增
```

与步行增量**不重复叠加**（同一段时间只算一次）。

**MET 取值**（出处一律写 Compendium of Physical Activities 2011）：
| 项目 | 档位 | MET |
|---|---|---:|
| 羽毛球双打 | 中低强度 / 中高强度 | 4.5 / 5.5 |
| 力量训练 | 轻 3.5 ｜ **常规抗阻 5.0（主值）** ｜ 大重量·多组短休息 6.0 | 3.5–6.0 |
| 跑步机·快走 | 6.4 km/h 平地 ≈ 5.0〔17190, 4.0 mph〕；**5.0 km/h ≈ 3.4–3.8**（平地 3.0 mph=3.3、跑步机 4.8–5.5 km/h≈3.8，**取 3.8**） | 3.3–5.0 |
| 跑步机·慢跑 | 7.2 km/h ≈ 7.0〔12020〕；8.0 km/h ≈ 8.3〔12030〕；中间线性内插（7.5 km/h → 7.5） | 7.0–8.3 |

🔴 **2026-10-31 修正**：旧表只写了「6.4 km/h ≈ 快走 5.0」一行，被我抄成「5.0 km/h ≈ 4.3」——
4.3 对应的是 **5.6 km/h（3.5 mph, 17200）**，5.0 km/h 套 4.3 会高估约 6.7 kcal。
子 profile 核算时把这个错反推回来了，**表里写死的数也要能被子 profile 纠**。

### 🔴 混合有氧必须分段算，不许整段套一个平均 MET

他说「慢跑+快走各半，20 分钟 2.08 km」这种时，**只能拿到总时长与总距离**，两段配速得反解：

```
第一步  平均配速 = 总距离 ÷ 总时长     ← 只用作交叉校验，不用来取 MET
第二步  按两段各自配速分别取 MET，分别算净增
第三步  距离闭合校验：两段距离之和 == 他报的总距离
第四步  配速闭合校验：分段加权平均 == 反推平均（偏差 <1%）
```

2026-10-31 实测：2.08 km ÷ 20 min = **6.24 km/h**；反解为慢跑 7.5 km/h×10min=1.25 km、
快走 5.0 km/h×10min=0.83 km → 合计 **2.08 km 闭合**，加权平均 6.25 vs 6.24，偏差 0.16%。

🔴 **反解出来的配速不是实测值**，报给他时必须说明「这组是能满足距离闭合的合理组合，
别的组合也能闭合」。同一组数据按 8.0/4.5 km/h 能算出有氧净增 133（比主值高 8 卡），
主值 125.2 落在这个带里——**给敏感性带，别把反解值说成他报的数**。

**实测样例**：
- 2026-10-24 胸部力量 47 min，MET 5.0 → `(5−1)×80.8×(47/60) = 253.2`
- 2026-10-26 羽毛球 80 min，MET 4.5 → `(4.5−1)×80.8×(80/60) = 377.1`
- 2026-10-30 胸部力量 35 min，MET 5.0 → `(5−1)×80.8×(35/60) = 188.5` → TDEE 2387.3
- 2026-10-31 背肌 43 min（MET 5.0 → 净 231.63）＋ 跑步机 20 min（慢跑 7.5/10min 净 87.53 ＋
  快走 3.8/10min 净 37.71）= **合计净增 356.87** → **TDEE 2555.62**（隐含 PAL 1.453），
  毛消耗 441.70，运动只占全天消耗 **14%**

🔴 **同一天既有力量又有有氧时，两项分别算再相加**，不要合成一个「63 分钟混合训练」取单一 MET。

## 赤字与目标

| 项 | 值 |
|---|---:|
| 推荐赤字带 | **400–550 kcal/天** |
| 折合减重 | 0.35–0.70 kg/周 |
| 换算常数 | 7700 kcal ≈ 1 kg 脂肪 |

低于 400：减得慢，长期容易原地踏步（不等于失败）。
高于 550：蛋白容易跟着砍掉，减脂期掉肌肉。

## 🔴 派生表铁律：用自身的实测锚点回代验算

本文件 2026-10-30 被抓出过一次真错：敏感性表用的公式（满额 `MET`）与同文件正文
（净增 `MET−1`）以及实测锚点（13000 步 → 274.7）**自相矛盾**，5000/7000/9000 三行
虚高 1.5 倍，并且已经据此向用户报过错数（「7,000 步进推荐带」）。

**规则（适用于本域所有区间表/敏感性表/档位表）：**

1. 表写完，必须挑**至少一个已有实测值**作锚点回代。锚点对不上 = 表错了，不是锚点错了。
2. 没有现成锚点时，用表内相邻行的**差值的恒定性**交叉验算
   （本表：每 1000 增量步必须恒为 27.47 kcal，任何一行不满足即错）。
3. 表里的公式符号必须与正文口径**逐字一致**（`MET−1` 就是 `MET−1`，不能一处写净增、一处套满额）。
4. 报给用户之前先自问：**这张表是我推的，还是我验过的？** 没验过的数不许说成结论。
