# 档案「改数 / 改口径」的连带更新清单（2026-11-02 实战）

> 触发：他补报克数、纠正菜名/品种、或拍板改口径（如「牛奶统一按 1.03 折算」「今天按休息档 PAL 1.2」）。
> 核心事实：**一份 diet 档案里同一个数会出现在 5–8 个地方**，只改表格行 = 上下自相矛盾，
> 下次回看会以为当初算错了。

## 一、谁改：派活还是自己改

| 情形 | 做法 |
|---|---|
| **新增一餐 / 新场景核算** | 派活给健康助理（它熟格式、会自己查条目） |
| **已有表格的克数 / 条目 / 口径修正** | **主 Hermes 直接改**（`patch` 逐处），不要再派活——派一轮 13–15 分钟，而改动是可枚举的 |
| **评估类（他还没点/没吃）** | 谁都不写档案，只出回复。**「打算吃」≠「已吃」** |

2026-11-02 实测：午餐克数改一次（160/110/170 → 120/80/80）触发了 **22 处 patch**；
牛奶口径改一次触发 **7 处**；虾嘌呤改品种触发 **7 处**。都是主 Hermes 自己改完再跑脚本验证的。

## 二、改动落点清单（照这张表走，少一处就矛盾）

改一个食材的克数或条目后，**逐项确认**下列位置有没有它：

1. **该食材的表格行**（热量/蛋白/脂肪/碳水/纤维/钠/钙/嘌呤 八列全改，不要只改热量）
2. **该餐合计行**（八列 + 可食克）
3. **供能比**（蛋白/脂肪/碳水 三个百分比）
4. **算术自检**（`P×4 + C×4 + F×9` 的算式与偏差百分比）
5. **蛋白密度**（g/100kcal）与 **蛋白 g/kg**
6. **能量构成 / 归因句**（如「脂肪 76.37 里 59.76 g 来自红烧肉（78.3%）」）
7. **嘌呤口径表**（每一项的克数 + 数值 + 借的表1-2 条目）
8. **敏感性档位表**（汁喝不喝、条目二选一、重量三档）
9. **早/午/晚小计表**与**全天合计表**（含「占目标」列的百分比与超/差量）
10. **验收/复核小节**里引用的旧合计值

⚠️ 还有一类容易被漏掉：**正文里散落的旧数**（如「本餐钠 549.49 只有午餐的 43%」「全天嘌呤 620.06 里午餐占 68.2%」）。
这些句子不在表格里，`verify` 脚本查不出来，只能靠下面的残留扫描。

## 三、改完必做的三步验证

### ① 先跑现成脚本

```bash
python "~/.hermes/skills/health/health-nutrition-analysis/scripts/verify_diet_tables.py" "<档案绝对路径>"
```

- **先数它报了几张表**——少一张 = 那张表被跳过了（合计行标签不是「合计」就会被跳过且**不报错**）。
- 「—」格被判「非数值」是预期内，看**重算出来的数字行与合计行是否一致**即可。

### ② 旧值残留扫描（关键，脚本查不到正文）

改完立刻把**旧值**当关键词全文搜一遍，一个都不该剩下（除了刻意保留的「已弃用/作对照」档）：

```python
import re
c = open(PATH, encoding="utf-8").read()
for s in ["1416.9", "813", "99.46", "566.24", "87.47", "1537.63", "207.15", "44.85",
          "1745.6", "620.06", "2198.8", "202.46"]:
    idx = [m.start() for m in re.finditer(re.escape(s), c)]
    if idx:
        print(f"--- {s} x{len(idx)}")
        for i in idx[:6]:
            print("   ", c[max(0,i-110):i+80].replace("\n", " "))
```

**判读**：命中的每一处都要人工看一眼，只有「对照档 / 弃用档 / 历史引用」可以留，
其余（尤其是正文归因句、小计表）必须改。2026-11-02 靠这一步抓到「全天嘌呤 620.06 里午餐占 68.2%」没跟着新值改。

### ③ 从磁盘读回，用脚本重算九列

不要相信「我改完了」这个印象。逐列加一遍，与合计行对齐后再报给他。

## 四、口径变更要「留痕」而不是「静默覆盖」

他拍板改口径时，档案里必须留下**变更记录**，否则下次数对不上无法回溯：

| 写法 | 例 |
|---|---|
| **变更标注 + 原话** | 「🔒 牛奶口径已统一（2026-11-02 他拍板「统一吧」）：液态奶一律 1.03 g/ml，200 ml = 206 g」 |
| **旧口径标作废、不回溯** | 「此前 10-26、10-31 两天按 1:1 记，差 3.9 卡/200 ml，旧档案不回溯修改」 |
| **降档/换口径后要给双档** | 休息档 1.20 作主值，常规档 A 1.25 保留为对照行 |
| **弃用的条目也要留一行** | 「鲜对虾 101.5（原主值，已弃用——品种不符）」 |

🔴 不要把旧口径那一行删干净。**删掉就无法解释历史档案为什么是那个数**，他事后核对会以为记错了。

## 五、改完汇报的固定形态

1. **先说他给的那一档变成什么**（逐项一行：新克数 → 新热量/脂肪/钠/嘌呤）
2. **改了什么口径**、为什么改、旧口径作废但旧档案不动
3. **新的合计**（该餐 + 全天 + 占目标）
4. **一句话复算结论**（脚本 PASS / 残留扫描干净）

不要重贴整张表——他上一轮刚看过，只需要看到**变化量和新的合计**。
