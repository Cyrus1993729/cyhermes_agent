# 「长期这么吃，体脂会不会降」实战 + 任务书断言被顶回（2026-10-26 夜间）

背景：当天（10-26）收盘账已定稿——摄入 1829.5 卡、运动净增 377.1、全天 TDEE 2575.8、
赤字 **746.3 卡（29.0%）**。他连着追问两轮：先问「今天赤字这么多是不是要瘦了」，
再问「每天 300–700 卡长期坚持，体脂会不会降」。

## 一、第一轮：「今天赤字这么多，是不是要瘦了」

**他特意加了一句定语**：「我说的是**长期**啊，指的不是明天早上的体重秤。」
→ 说明他自己已经知道秤不准，**要我谈趋势，不是单日**。这正好落在「他问能不能减下来时才引用速度上限」的窗口里。

### 周均换算

```
746.3 卡/天 × 7 = 5224.1 卡/周
5224.1 ÷ 7700 = 0.678 kg 脂肪/周
```

对照 0.35–0.70 kg/周（⚠️ 用保守口径，见 SKILL.md「减重速度」节）：

| 周减 | 对应日赤字 |
|---|---:|
| 0.35 kg | 385 卡 |
| 0.70 kg | 770 卡 |

**746.3 落在带上沿，离上限只差 24 卡/天**——即：这一天本身合规，但**已经没有余量往上走**。

### 三条不确定性（必须三条齐，不许只报好消息）

1. **误差 ±200 卡** → 周均 0.50–0.86 kg。来源：午餐炖油 3g 与鸡蛋羹 1.5 枚是推算、
   Mifflin 公式本身 ±10%、PAL 1.25 是假设值、MET 三档之间就差 162 卡。
2. **明早大概率涨 0.5–1.5kg**——钠 3797.8mg（≈9.5g 盐）+ 碳水 210.8g，糖原每克带 3g 水。
   **那是水，不是脂肪。**
3. **这个赤字不可复制**：当天能到 746，是三件事同时发生——基线 TDEE 2198.8 本身就比 2000 目标高 198.8、
   运动净增 377.1、摄入又低于目标 170.5。**29% 赤字 + 190% 钠，是一个极端日。**

### 🔴 健康助理在这里编造了一条事实——必须核

它在解释「赤字为什么这么大」时写：

> 「今天能到 746，是因为**早餐没吃**（省 350 卡）」

**错。当天早餐 350.1 卡早就存档在案。** 存档小节本身没错，错的是回答里的叙事，**grep 查不出来**。

**正确的归因**（主 Hermes 自己补齐的）：
```
基线 TDEE 2198.8 比 2000 目标高     +198.8
羽毛球净增                          +377.1
摄入 1829.5 比 2000 目标低          +170.5
─────────────────────────────
合计                                746.4
```
→ **赤字主要来自「代谢 + 运动本身就超过 2000 这个目标」，不是靠少吃一顿。**

**本条已写进 SKILL.md**：转述前拿档案逐条核对话里的「事实性断言」（吃没吃、哪一餐、有没有运动）。

## 二、第二轮：「每天 300–700 卡长期坚持，体脂会不会降」

**先一句话给判断：会降。** 然后才是四层拆解。

### 区间换算（他给的下沿是无效的）

```
300 卡/天 × 7 = 2100 卡/周 ÷ 7700 = 0.27 kg/周   ← 在带外，偏慢
385 卡/天 × 7 = 2695 卡/周 ÷ 7700 = 0.35 kg/周   ← 刚进带内
500 卡/天 × 7 = 3500 卡/周 ÷ 7700 = 0.46 kg/周
700 卡/天 × 7 = 4900 卡/周 ÷ 7700 = 0.64 kg/周   ← 仍在带内，接近顶
770 卡/天 × 7 = 5390 卡/周 ÷ 7700 = 0.70 kg/周   ← 硬上限
```

→ **「300 到 700」实际有效的是 385 到 700。**

### 赤字 ≠ 一定掉脂

同样 400 卡赤字，掉 350g 脂肪 与 掉 200g 脂肪 + 150g 肌肉，**体重秤上一模一样，体脂率差很多**。

分水岭两条：

| 条件 | 他当时的状态 |
|:--|:--|
| **蛋白摄入** | 117.49g = **1.45 g/kg**；目标 129g = **1.6 g/kg**，**差 11.5g** |
| **抗阻训练** | ✅ **满足**——每周 2–3 次（见下方错误） |

**结论：真正的缺口是蛋白那 11.5g，不是训练。**

### 代谢适应：赤字会自动缩水

```
体重 80.8 → 75.8 kg（减 5kg）
Mifflin BMR 系数 = 10×kg → BMR 约 −50 卡
TDEE（×1.25）约 −62 卡
运动净增也随体重下降（体重是乘数）
```

→ 「每天固定 300–700」到后期自然会变成更小的赤字。**这是身体变小了，不是执行不到位。**
不主动说这条，他会以为自己方法失效了。

### 尿酸约束：别往 700 那端长期待

尿酸 **454**，距药物门槛 480 **只剩 26**。大赤字时酮体与尿酸抢同一条肾排泄通道，
尿酸容易被顶高 20–40。

```
400 卡/天 → 0.36 kg/周
550 卡/天 → 0.50 kg/周
```
→ **400–550 是给他的位置。**

监测方式只有一条：**减重开始后 4–8 周抽一次血**（尿酸 / LDL-C / TG / ALT）。
不必每天记任何东西——这符合他「拒绝持续手动记录」的底线。

### 判据仍是他自己定的

**体脂降，不是体重降。** 看两样：
- **腰围**：同一位置、同一时间，2–3 周量一次
- **力量**：同样的重量能不能推同样组数


### 为什么这类错特别要防

- 算错数他会质疑，**写错「你只有羽毛球」他会不服，而且他是对的**
- 它直接否定他已经坚持在做的事——这比一个数字偏差更伤
- 健康助理会去核档案，所以**这类断言它一定会发现**，然后你就得当着用户面认错

**判据：任务书里凡出现「他只有 / 他从不 / 他没有」，先 grep：**

## 四、这一轮的可用模板

他问「长期会不会瘦」类问题时，回复结构：

1. **一句话判断**（会 / 不会，别绕）
2. **区间换算表**（他的区间 → kg/周 → 对照 0.35–0.70 带）
3. **指出他哪一段是无效的**
4. **赤字 ≠ 掉脂**，分水岭两条
5. **代谢适应**：赤字会自动缩水
6. **尿酸约束** → 给他落在 400–550
7. **判据：腰围 + 力量，不是秤**

**不要给分周执行框架、不要给每周计划表**——他要判断，不要方案。
