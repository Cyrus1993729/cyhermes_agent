## 一、运动记录（2026-11-18 羽毛球双打）

### 原话

> 让健康助理记一下，我刚刚打了大概60分钟中等强度的羽毛球双打。

### 档案落点

```
## 运动（口述直录 ＋ MET 换算）      ← 新增，插在「今日汇总」之前
## 今日汇总（截至 20:16，**仅含已报餐次 ＋ 本次运动**）   ← 重出
头部状态行同步改：早餐 ＋ 午餐 ＋ 加餐 ＋ 运动已报（截至 20:16）。晚餐未报。
```

### 为什么运动节不并进营养表

营养表是 **11 列固定结构**（食材/来源/克/热量/蛋白/脂肪/碳水/纤维/钠/钙/嘌呤），校验器按列位重算合计。运动行的列是 MET/总消耗/净消耗，**不同构**，混进去会让校验器列对不齐。

做法：运动节自己用一张 7 列小表（项目｜时长｜强度｜MET｜体重基准｜总消耗｜净消耗）＋ 代码块写换算过程。校验器只扫「早餐/午餐/加餐/晚餐/加餐N」这类餐次名，抓不到运动节，所以 ALL PASS 不受影响。

⚠️ 反过来说：**运动节的标题不要用会被餐次正则命中的名字**，否则校验器会拿 11 列去解析一张 7 列的表然后报错。

### MET 取值与出处（2026-11-18 实际用的）

```
MET 5.5 —— Compendium of Physical Activities 2011（Ainsworth 等）
  code 15030「badminton, social singles and doubles, general」= 5.5 METs
  🔴 该 code 不区分单打/双打（条目名本身就写 singles and doubles）→ 合并档
  竞技比赛是另一条：code 15025「badminton, competitive」= 7.0 METs，中等强度双打不采用
```

### 公式（档案例行口径 = 取净增量）

```
总消耗 ＝ MET × 体重(kg) × 小时
净消耗 ＝ (MET − 1) × 体重(kg) × 小时      ← 计入能量账户的是这个

5.5 × 77.0 × 1.0 ＝ 423.50 卡（总）
4.5 × 77.0 × 1.0 ＝ 346.50 卡（净）
```

总消耗里那 77 卡是躺着不动也会烧的，不能算成运动增量。

### 体重基准

取 `profile.md` 现行工作口径 **77.0 kg**（他 2026-11-16 本人指定「按空腹 77 公斤来算」；真实晨起空腹裸重 76.4 kg / 2026-11-12 另存）。运动核算与 BMR/TDEE **同口径**，都用 77.0。

### 时长区间（他自估时必须给）

```
45 min：净 259.88 卡｜总 317.63 卡
60 min：净 346.50 卡｜总 423.50 卡   ← 采信他说的 60 分钟
75 min：净 433.13 卡｜总 529.38 卡
```

主值用他说的数，区间只做参考，**不取中值**。

### 对汇总的影响（只改一项）

```
基线 TDEE        2151.25 卡（BMR 1721 × PAL 1.25）
本次运动净增   ＋ 346.50
今日总消耗       2497.75 卡

钠 1160.81、嘌呤 401.18 —— 不随运动变化，账面数不动
```

## 二、剩菜 / 隔餐结转（2026-11-18 晚餐）

### 原话

> 吃的是昨天剩下的另一半番茄猪肉丝当然了，食材不止番茄跟猪肉丝这两样啊，之前说的什么香干呀？圆葱呀娃娃菜呀等等就昨天不是吃了一半吗，剩的，然后今天都把吃掉了，然后另外还是配了150克的白米饭。

### 关键判断：等量 ×1，不重算

昨天（2026-11-17）档案 `## 晚餐（口述直录 ＋ 小红书菜谱还原）` 第 225–237 行记的**已经是「整锅的一半」**（他当时原话：「这些菜我吃了一半，剩下的一半放在冰箱里准备明天吃」）。

所以今天吃的那一半 **与昨天那些行完全等量** → 任务书写明「**×1 沿用昨天已核定的行，克数、各项数值一个都不许自己再调**」。

### 整锅 13 项清单（他提醒「不止番茄跟猪肉丝」时要全列）

番茄、番茄膏、娃娃菜、香干、猪肉丝（纯瘦）、小圆洋葱、橄榄油、蒜末、花雕酒、生抽、盐、黑胡椒、白胡椒。

任务书里写死：「**『等等』＝这 13 项里的其余项，以昨天表为准，不要自己加也不要漏**」。

### 三条不许动的口径

1. 昨天那些〔估算〕调料克数（生抽 8 g／盐 1.5 g／花雕酒 10 g／黑白胡椒各 0.5 g／蒜 6 g 整锅）→ **沿用昨值 ×0.5，不许重新估**。两轮估出两个数就对不上账。
2. 猪肉丝按**纯瘦**口径（昨天他本人拍板：「猪肉挺瘦的…你按瘦肉丝算问题不大」）。
3. 用油只算橄榄油（他明确「只放橄榄油，没放别的油」）；花雕酒按 80% 酒精挥发、残留 20% → 13 卡/100 g。

### 🔴 R1 补正过的字段必须带上

2026-11-17 的 `## 📌 修订 R1（钾补正）`：晚餐「猪肉丝（纯瘦）」75 g 的钾当时**漏取**，补 `zhurou_shou` 钾 305 mg/100 g × 75 g ＝ **228.75 mg**。

今天这锅剩菜等量重来，**漏了就是同一个漏犯第二次**。任务书里点名带上。

### 派活前的只读核查（允许主 Hermes 做）

```bash
# 证明剩的半份没被今天别的餐吃掉
grep -c "番茄\|香干\|娃娃菜" <今天档案的已入档餐次行区间>
# → 0 即无重叠
```

2026-11-18 当天午餐是糖醋排骨 100 g／小炒鸡 80 g／炒青菜 80 g／炒花菜 80 g／白米饭 100 g，与这锅无重叠，剩的一半完整。**这个结论要写进任务书**，让 bot 不必自己猜。

### 主食不折半

「另外还是配了 150 克的白米饭」——另吃、不在锅里，**不跟着半份一起折半**，按熟重 150 g 全算。
