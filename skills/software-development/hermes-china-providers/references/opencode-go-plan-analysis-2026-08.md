# OpenCode Go 套餐评估（2026-08-14 调研）

OpenCode 官方订阅制模型服务（Go 套餐）完整调研。背景：DeepSeek 官方 8/17 峰谷涨价后，用户评估 OpenCode Go（$10/月）替代 DeepSeek 官方 API / 停 Claude 订阅。数据源：opencode.ai/docs/zh-cn/go（2026-08-12 更新）+ bitdoze/lautenbacher 实测。

## 套餐结构
- 首月 **$5**，之后 **$10/月**，支付宝可付
- 全局限制：**$12/5小时、$30/周、$60/月**（按美元价值计，非请求数）
- **额度按模型独立**（关键机制！）：每模型有自己的额度上限（见下表），便宜模型 $60、旗舰模型 $15——**Flash 用不完不能转给高级模型**
- 超出限制可开 "Use balance" 回退 Zen 余额（按量付费）

## 关键测算口径（比官方请求数更真实）

⚠️ **官方"典型请求"假设 ≈ 51-68K 缓存 tokens/次；Hermes 实际请求平均 198K tokens（98% 缓存命中）**——按美元计我们单次请求成本是官方典型的 ~3 倍，**官方月请求数对我们要打 3 折**。

用户月用量画像（2026-08-01~14 实测外推整月，agent.log 统计）：
- ~4,000 次调用/月：**日常对话 81%**（~3,200 次）+ 日报 19%（~800 次，单次日报 21-101 次 API 调用）
- 输入 786M tokens（98% 缓存命中）、输出 5.2M
- 5h 窗口峰值：平时 50-150 次，重活日（8/7 批量任务）415 次/5h

## 各模型可用性分级（结合我们用量）

**只跑日报（~800 次/月）**：
- ✅ 全部可用（含 Luna $4.3/29%、Pro $2.4/16%）
- ❌ Grok 4.5（$55.8 vs $15）、Kimi K3（$63 vs $15）、Qwen3.8 Max——月额度爆 4-9 倍

**日报 + 日常对话（~4,000 次/月）**：
- ✅ 随便用：Flash、MiMo-V2.5（10%）
- ⚠️ 够用但紧：Hy3（54%）、Qwen3.7 Plus（76%）
- ❌ 会超额：Pro/MiMo-Pro（96% 顶格）、Luna（165%）、MiniMax（95%）、GLM-5.2（217%）、Grok/K3/Qwen3.8Max（爆表）
- 🚨 5h 墙：重活日 415 次/5h 时 Grok/K3 必撞 $12 墙，GLM 也危险

**结论**：Go 套餐现实分工 = 日常 Flash/MiMo 畅用 + 日报可升 Luna/Pro + Grok/K3 只够尝鲜（几十次/月）。$15 档旗舰（Luna/Grok/K3）只能当"日报专用或低频审查"，对话跑会超 2-9 倍。

## 与官方 API 对比（8/17 涨价后）
- 官方按量：我们日报 11:00/17:00 都在高峰时段（9-12、14-18）→ flash 高峰价 0.10/3.0/9.0 元 → 全量月成本 ≈ 80 元
- OpenCode Go：$10/月 ≈ 72 元，Flash 额度只用 10-19%
- 空闲时段挪日报（12:30/18:30）：官方 40 元/月（延迟未实测）

## Hermes 接入姿势
- OpenAI 兼容 endpoint：`https://opencode.ai/zen/go/v1/chat/completions`（bitdoze 提供 Hermes 配置示例：OPENAI_BASE_URL/OPENAI_API_KEY 或 custom provider）
- 模型 ID 格式：`opencode-go/deepseek-v4-flash` 等
- 服务器海外（US/EU/Singapore）→ 需走代理（本机 7897）
- 隐私：Grok/Luna 保留日志 30 天（滥用监控），其余 0 天

## 评估遗留
- 用户停 Claude 订阅后，5 步闭环 sign-off 可用 Go 的 Luna/GLM-5.2 替代（低频审查月成本 ~$1-6，额度 6-40%）——需实测审查质量对比
- ZDR 8/31 到期后 OpenCode 是否调整 Flash 定价/额度 = 最大不确定项
