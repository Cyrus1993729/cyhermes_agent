# 扫描件 OCR（无文字层文档）

处理拍照/扫描生成的 PDF、图片类文档——它们**没有文字层**，`read_file` / `pdftotext` 都拿不到东西。

配套：`pdf` skill（bundled）负责有文字层的 PDF；本 skill 专门负责**需要 OCR 的那一类**。

---

## 一、先诊断：确认是"真的没文字层"

```bash
read_file  → NeedsOcrError: all N pages need OCR   ← 已确诊
```

交叉确认（两秒，值得做）：

```bash
pdftotext -layout "in.pdf" out.txt && wc -c out.txt
# 输出只有 N 个换页符（\f）= 零文字层。例：21 页 → 21 字节
```

> ⚠️ 不要因为 `read_file` 报错就说"读不了"。这是**可解的**，往下走。

## 二、渲染：用 `uv run --with pymupdf`（零安装）

**不要先去装 poppler / marker-pdf。** `pdftoppm` 常常没装，而 marker-pdf 要 3–5GB。

```bash
cd "$LOCALAPPDATA/Temp"
uv run --quiet --with pymupdf python render_pdf_pages.py "<pdf绝对路径>" "<输出目录>" 180
```

- `uv run --with <pkg>` 临时拉包跑脚本，**不动系统环境、不需 pip、不需 venv**
- 本 skill 自带 `scripts/render_pdf_pages.py`（逐页存 PNG + 打印尺寸/KB）
- **180 DPI 够用**（A4 → 1488×2105）；低于 120 小字会糊

## 三、识别：`vision_analyze` 逐页

question 用固定模板（要求逐字 + 结构化，否则会给你一段概括）：

```
逐字读出这一页的所有文字。如果有结果表格，请按
"项目名称 | 结果 | 单位 | 参考范围 | 提示(↑↓)"的格式逐行列出。不要总结，原样输出。
```

🔴 **这是关键**：一律要求**逐字 + 禁止总结**。医疗单、账单、合同的漏字/改数后果严重。
🔴 **表格类文档必须连"参考范围"和"↑↓提示"一起抄**——只抄结果值等于丢了一半信息。

### 🔴🔴 泛问≠定向问：**不指定位置，Vision 会告诉你「没有文字」**

上一条说的是「禁止总结」，还有另一层：**不指定文字在哪，它会当成背景装饰直接跳过。**

2026-10 实踩：一段视频有檕烧字幕（白字黑阴影，就在画面底部），泛问时返回——

```
❌ 「逐字读出画面所有文字，并描述画面里在做什么」
   → 「经仔细查看，画面中没有任何文字内容。」   ← 字幕明晃晃就在那儿

✅ 「只看画面底部的中文字幕（白色带阴影的字），逐字读出来。
     如果没有字幕就回答"无字幕"。」
   → 「锅里加少许的橄榄油」✅
```

**三个要点：**

1. **告诉它「看哪里」**（底部字幕 / 表格区域 / 卡片区 / 图例）——位置是把 OCR “叫醒”的开关
2. **描述特征**（「白色带阴影」「小块棕色圆体字」）——比单纯给坐标更稳
3. **给它一个诚实出口**（「没有就答"无字幕"」）——**不给出口它会为了迎合预设而编一行假字幕**

**推广**：同一个道理也适用于「图中没有这个字段」的判断。如果你问「这张图里写了多少钱」，
模型会倾向於报一个数；问「如果图上没写金额，答"未标注"」，它才会诚实。
**永远给识别任务留一条「不存在」的退路。**

### 视频/图片序列里的数据卡：先低分辨率扫，再原尺寸精读

内容型视频（食谱/健身/记账/参数演示）常在开头几帧**叠一张数据卡**——
那是整段里信息密度最高的东西，但低分辨率抽帧会糊到数字读不出。

```bash
# ① 低分辨率扫，先找哪几帧有卡
ffmpeg -y -i video.mp4 -vf "fps=1/1.5,scale=720:-1" frames/f_%03d.jpg

# ② 定位到后用 -ss 抽**原尺寸帧**（不缩放！）
ffmpeg -y -ss 2.8 -i video.mp4 -frames:v 1 -q:v 2 ncard.jpg
```

配合第 三 节的 `region` 参数框住卡片，数字才逐位准确。
**读出来必须做算术自检**（各项相加、宏量×4/9/4 回算总热量），**自检不过就是读错了，重读。**

⚠️ **`fps=1/1.5` 只覆盖平均位置**，转折点（卡片弹出/消失）容易错过。
**关键数据没找到时，不要结论「视频里没有」——先按 0.5s 间隔补扫前 5 秒。**

### 可信度排序：数据卡 > 画面实物 > 标题 > 封面

实测一条笔记：标题写「菜心牛肉炒饭」、封面写「卷心菜牛肉炒饭」、
而数据卡和锅内画面确认真的是**菜心**。

封面往往是运营做的、可能用旧模板；标题和正文是作者本人写的；**数据卡是称过/算过的**。
多源冲突时按这个顺序取值。

## 四、规模化：>5 页就派子代理

**不要把十几张图逐张过主上下文。** 本次 19 页图片如果全在主会话里过，上下文直接翻一倍。

```
delegate_task(goal=逐页 OCR 第 N–M 页 → 完整结果写入 <绝对路径>.md,
              context=图片路径规律 + 逐字要求 + 输出路径 + 校验锚点)
```

给子代理的 context 必须含这四样：

1. **图片路径规律**（`p03.png` 到 `p21.png`，两位数补零）
2. **逐字要求 + 禁止总结**（写明白"这是医疗/财务数据，漏一个数字后果严重"）
3. **输出文件绝对路径**（让它直接写文件，不靠它的 summary 回传）
4. **交叉校验锚点**（见下节）

它完成后**读它写的文件**，而不是只看它的总结。

## 五、校验：锚点 + 覆盖率（不可省）

### 5.1 锚点交叉校验

开跑前先想好**几个已知值**当锚点（用户口述过的、其他来源的、上一次记录的），喂给子代理：

> 背景：这份报告的已知值包括 A=…、B=…、C=…。你提取的应该能对上；
> 对不上就说明抄错了，回头重看对应页。

拿到结果后**自己再校一次**（不靠它的自述）：

```bash
for v in "6.91" "3.27" "4.37" "454" "6.3"; do printf "%-6s " "$v"; grep -c "$v" out.md; done
```

锚点全中 → 提取可信；有一个不中 → 让它重看那一页。

### 5.2 覆盖率校验

```bash
grep -n "^## 第" out.md      # 应连续覆盖要求的页段，不缺页不重复
grep -c "^## 第" out.md      # 数量对不对
```

子代理可能少跑页或多跑页，**这一步拦得住**。

⚠️ **但它只拦"整页缺"，拦不住"单页被截断"**——视觉模型的输出在 token 上限处会被
默默砍掉，那一页看起来在、实际上末尾少了。**长表格页要额外核对末行**
（合计行、参考范围列、最后一项），必要时拆成两次识别。

> 同类教训（另一条管线实测）：视觉模型先输出 ` thinking` 推理时，**思考过程本身就吃掉
> 大量 token**，留给结构化输出的额度被挤没了。症状会伪装成"模型结果不稳定"——
> 同一张图跑两次结果不同，其实是每次都截断在不同位置。
> **遇到"LLM 输出每次都不一样"，先查是不是被输出上限截了，再怀疑采样随机性。**

## 六、落地：原始件与整理稿分开存

```
<域根>/records/
  2026-10-10_体检.md      ← 整理稿（给人看/给分析用）
  _raw_ocr.md            ← 原始逐字 OCR（不动）
```

🔴 **别只留整理稿。** 把原始 OCR 也存下来，整理稿开头写明"原始件在 `_raw_ocr.md`"。
实测价值：后续让另一个 agent 穿透审阅时，它**正因如此才能回原始件核对**，
结果抽出了整理稿里 4 处错误（原文没有的分级、两页数字不一致、推导区间算错、描述与结论矛盾）。

**整理稿里要标明每个事实的来源**：报告原文 vs 用户口述 vs 推断。
三者混在一起时，以后无法判断哪些可信。

## 七、坑速查

| 坑 | 现象 | 处理 |
|:--|:--|:--|
| 以为读不了 | `read_file` 报 NeedsOcrError | 这是可解的，走本流程 |
| 先装重型依赖 | marker-pdf 要 3–5GB | 先用 `uv run --with pymupdf` 渲染 + vision |
| `pdftoppm` 不存在 | command not found | 不经它，用 pymupdf |
| MSYS 路径不认 | `python /tmp/x.py` 报 No such file | 先 `cd` 用相对名，或传 `C:/...` 正斜杠绝对路径 |
| 前台超时 | 批量渲染/识别跑很久 | 用 `background=true`；超时后先查产物再判定失败 |
| 子代理报"完成"但文件没写 | 只信了它的总结 | 一律回读它声明的输出文件 + 查字节数 |
| 表格丢了参考范围 | 只抄了结果值 | question 模板里强制要求 |
| 页码对不上 | 少跑/多跑页 | `grep -c "^## 第"` 覆盖率校验 |
| **单页输出被截断** | 该页末尾/表格**最后几行静默消失**，不报错 | 长表格页刻意核**末行**（合计行、最后一项）；行数很多就拆成两次识别 |
| **泛问得到「没有文字」** | 字幕/小字明明就在，模型却说无 | **指明位置 + 描述特征 + 给「不存在」的出口** |
| **低分辨率帧读不清数字** | 数据卡上的数字模模糊糊 | 用 `-ss` 抽**原尺寸帧** + `region` 框选 |
| **抽帧间隔错过关键帧** | 数据卡一闪而过没抽到 | 按 0.5s 补扫前 5 秒；**不要结论「视频里没有」** |
