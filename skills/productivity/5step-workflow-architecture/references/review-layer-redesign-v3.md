# 审查层重构方案 v3.0（讨论产物）

> 状态：设计完成，待用户确认后实施。Opus 评分 82/100，Codex 评分 84/100。

## 核心变化

旧：千问 L1（6维审查+疑点标记）→ Opus L2（仅审疑点）
新：Codex（正向重建验证）+ Opus（反向证伪）并行全量审查，千问退场转盲审第三模型

## 审查层

- Codex 主责 D1/D3/D6（可重做验证），Opus 主责 D2/D4/D5（需判断对抗）
- 都审全部6维，站位不同+主责错位（陪审方轻扫）
- 统一 JSON schema，每条 finding 必须带可定位证据

## 裁决流程（6步）

1. 接地校验 → 2. 归并 → 3. 分歧路由（事实/价值）→ 4. 事实类自动收敛（交叉质证→定点验证→千问盲审→补证据）→ 5. 自动修复（≤3轮，全量6维重审）→ 6. 价值类上抛（翻译成选择题）

## 关键原则

1. 技术事实系统裁决，价值取舍用户裁决
2. 接地校验是地基
3. 默认自动收敛，上抛窄例外
4. 证据等级 > 模型票数
5. 修复≤3轮+全量重审+震荡检测
6. 上抛=选择题
7. 影子先行数据说话
8. 复盘回写契约
