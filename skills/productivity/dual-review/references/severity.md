# 严重度定义

| 级别 | 定义 | 阻断 |
|---|---|---|
| critical | 安全/法律/资金/数据丢失/不可逆 | ✅ 立即阻断 |
| high | 核心验收标准未满足/关键结论被推翻 | ✅ 阻断修复 |
| medium | 不改变核心结论但降低可靠性 | 🟡 条件放行 |
| low | 风格/表达/非必要优化 | ✅ 放行 |

## 通过门禁

- 存在已接地 critical → 不得通过
- 存在已接地 high → 不得自动通过（除非修复+重审）
- 仅有 medium/low → PASS_WITH_NOTES
- 全部关闭 → PASS
- 熔断/不可用 → 上抛
