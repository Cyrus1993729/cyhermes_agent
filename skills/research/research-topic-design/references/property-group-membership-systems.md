# 地产集团"大会员"体系 —— 调研知识库（2026-09 整理）

## 概念与判定

大会员 = 集团内多业态的会员身份 / 积分 / 权益打通为统一用户资产：One ID + 统一成长值 + 通用积分 + 权益池。
**判定标准：积分与等级能否跨业态累积与流通。**不能 → 那只是几个单体会员贴牌。

## 龙湖 珑珠（2021 上线）

- 10 珑珠抵 1 元，1 珑珠也花（无门槛）；**V1–V5 五档等级**，等级越高抵扣倍数越大（膨胀抵扣）
- 会员 4000 万+（2023.11 口径）
- **赚**：购房签约返、天街/星悦荟消费、冠寓签约 + 每期租金（续租返更高比例 ← 留存设计）、物业缴费、U享家消费、塘鹅租售、龙湖优选
- **花**：抵房款（按等级倍数）、抵天街消费、抵停车费（V3+ 免费停车）、抵冠寓租金/换房券/月付券、抵物业费、外部兑换（途虎/美团/视频会员/星巴克/奈雪/盒马，覆盖日常 80% 场景）
- 架构：**多前端一后台**（U享家 / 天街 / 冠寓 / 塘鹅各自小程序做入口 → 统一后台，手机号即 One ID）
- 核心公式：**高频赋能低频**——用高频购物中心会员赋能低频住宅销售
- **支核一体**：佣金、活动奖品、老带新奖励均以珑珠发放（省采购流程、省人力、减少税费）
- 效果：销售费用率 2020→2022 降 0.60pct（2.73%→2.13%）
- 短板：营销费用驱动（业界指其投入大、非利润中心）；跨 BU 利益需顶层压；积分 = 递延负债

## 华润置地 万象星（2022.05 上线）—— 业态最接近 TOD

- "2+1"战略 = 物管 + 商管 + 大会员生态
- **8 大业态**身份通/积分通/权益通：营销、康养、长租、酒店、文体、影业、物业、商业
- 会员：3200 万(2022) → 3990 万(2023.11) → 4625 万(2023 底) → **7200 万(2025 中)**；积分年发放 5.9 亿元(2025H1)，同比 +18%
- 三步走：华润置地内 → 华润集团内 → 异业开放
- 定位：**利润中心而非营销费用中心**（与龙湖的分野）
- 数据点：购物中心与住宅重叠会员人均年消费 2.5 万元，为普通会员 **2.8 倍**
- 子平台：悦家 APP（住宅物业）、一点万象（商业）、Officeasy（写字楼）

## 招商蛇口 招商荟 / 其他

- **联邦制**：独立前端 + 独立后台，各板块引流至统一平台（适用于邮轮/园区/食品/大健康等弱关联业态）
- 300 万 C 端用户、50 城、活跃度 25%；2020→2022 销售费用率降 0.35pct
- 合景泰富"合景一合"：**拉通容易、持续盈利难** —— 反面教材
- 茑屋 T 积分：数据中台对外赋能收费，连接 100 万外部门店 —— 终极形态，非初期目标

## 两种管理模式

- 多前端一后台（龙湖珑珠、金茂金钡）：业态强关联、集团管控强
- 独立前端独立后台 / 联邦制（招商荟、越秀悦秀会）：弱关联业态多

## 行业共识与坑（写方案时别只抄优点）

- 大会员是"**事后拉通**"的产物：龙湖/华润都是存量业态跑起来后才打通，无一家在开发期预埋
- 大会员**不制造首次转化，只放大已发生的转化**——积分拦不住赶车的人（首次进店靠商业内容、动线、便利性）
- 枢纽客流必须分层：长途客（不可留存，只能做单次价值最大化）、商旅（酒店会员模型）、**通勤客（日频，真正的留存战场）**、接送/周边客
- 落地需集团顶层设计 + 长期投入；跨业态利益分配是政治问题
- 常见误命题："把过路客变成回头客"（大会员使不上力）、"建体系→交叉消费↑"（同义反复）

## 苏州东站 TOD 课题上下文（2026-09 ~ 10）

**公司业态**：住宅 + 商场 + 办公楼 + 酒店（同一块地，站域空间闭环）。

**小组能力画像**：工程 ×2、财务 ×1、设计 ×1、住宅前期定位 ×1（用户本人，龙湖背景）、招商运营 ×1（龙湖背景）。
→ 能力 = 算账 / 客户认知 / 机制认知 / 商户沟通；**弱项 = 系统搭建、中台、数据底座**。命题必须绕开弱项。

**汇报框架（六模块，19 分钟 + 评委提问 5 分钟）**：
1. 课题背景与问题提出（3min）
2. 课程方法与分析过程（3min）
3. 解决方案（上）：方案框架、核心策略（3min）
4. 解决方案（下）：方案细节、工具表单、关键节点（3min）
5. 成果展示与落地计划：阶段性成果 + 后续行动步骤（3min）
6. 总结与学习收获：含封面与致谢（4min）

**时间节点**：9/17 前组长确认课题 + 提交《小组分工表》；9/30 前交全员培训心得 + PPT 初稿 + 至少 1 次演练；10/8 前确认 PPT 终稿。

**当前收敛方向（未经最终拍板）**："让利形式的重构"——同样的营销让利，直接降价 vs 积分化（发珑珠/抵房款），在 TOD 商场+住宅同域场景下如何权衡；机制设计与算账为主、体系搭建仅作背景。
