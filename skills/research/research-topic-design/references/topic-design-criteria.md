# 命题判据与反例（速查）

帮用户设计课题/研究命题时的自检清单，来自 2026-09 苏州东站 TOD 大会员课题的三轮收敛。

## 命题体检表（每一问都必须过）

| 体检项 | 不合格的表现 | 修法 |
|---|---|---|
| 有对立面吗？ | 结论由定义直接推出（做 X → X 的目的达成） | 找出"另一种做法也有人认真主张"的那个点 |
| 有真痛点吗？ | 痛点是想象的，业务上其实没人在痛 | 换成行业公认没解法的环节（如跨业态利益分配） |
| 团队答得出吗？ | 需要黑箱经验（系统搭建）或外部人脉访谈 | 降到机制设计 / 算账 / 客户研究层 |
| 产出有形吗？ | 只能产出认知报告或活动策划 | 要有机制表 + 测算表 |
| 结论能变成行动吗？ | "推动落地"模块写不出下一步 | 结论必须能直接指导下周的工作 |

## 三个真实反例（用户亲自否掉的）

1. **"大会员体系把高铁过路客流转化为复购用户"**
   - 否掉原因：大会员不制造首次转化。它只作用于"首次消费之后"（召回、复购、跨业态导流），首次进店靠商业内容与动线。
   - 附带教训："过路客流"是伪群体，须分层（长途客/商旅/通勤客/接送客），主战场是日频的通勤客。
2. **"建大会员体系提升跨业态交叉消费"**
   - 否掉原因：同义反复，没有对立面。评委看开头就知道结尾。
3. **"开发期预埋大会员体系"**
   - 否掉原因：命题本身好、有原创性，但需要"终局反推"的系统搭建认知，小组无人具备，且要大量外部信息与人脉。**好命题 ≠ 好课题，必须过能力关。**

## 收敛到的判据（可复用）

- 好问题 = 两难 + 能力够得着 + 产出有形 + 领导能用。
- 命题表述被批"宽泛"时，通常不是措辞问题，是缺对立面；换词没用，得换矛盾。
- 组员参与度也是判据：好命题应让每个成员（财务/招商/前策/工程/设计）都有可贡献的一块。
