# 咨询话术模板（纯文本，可整段复制）

> 用户偏好：可整段复制编辑的纯文本，不要选项按钮/数值档位。
> 用法：把方括号占位替换成实际内容，其余照抄。

## A. 通用四问式（园区 / 载体 / 二房东）

```
您好，我想咨询贵园区的入驻和注册地址问题，一共四点：

1. 贵园区能否提供属地登记机关（[属地市场监管局名称]）
   认可的合规注册地址？形式是集群登记、住所托管协议，
   还是共享工位对应的具体工位号？该地址目前在市场监管
   系统里是什么状态、能否用于新公司设立登记？

2. 如果能，需要什么条件和费用？是否要求必须实地办公？
   最少租几个工位/多大面积？年费大概什么区间？

3. 扶持政策：[业务方向，如跨境电商/实物商品出口] 目前有哪些
   可申报的扶持？包括场地租金减免、算力补贴、[专项]奖励、
   首次开办补贴等，分别由哪个部门兑现、什么时候申报。

4. 我这边是一家新设公司，[股权结构，如股东为家人代持]，
   主营 [具体业务]，团队规模很小。这个情况是否符合入驻门槛？

另外想确认：贵方是园区产权运营方，还是二房东/招商代理？
```

## B. 政府窗口版（问政策口径，不问场地）

```
您好，我想咨询 [事项] 的政策口径：

1. [属地] 目前对 [主体类型] 有没有住所托管 / 集群登记的
   正式制度？适用条件和办理材料是什么？

2. [行业] 方向有哪些现行可申报的扶持政策？申报时间窗口和
   兑现部门分别是哪个？

3. 如果后续涉及注册地址核验，我应该找哪个窗口查该地址
   在系统里的备案状态？

另外想请问，这件事由哪个部门归口？如有更对口的电话请告知。
```

## C. 收口句（要对方给明确答复，避免被电话推销带走）

```
我先只要政策口径和准入条件，暂时不需要推荐场地报价。
如果贵方不是这块的答复方，麻烦指个对口的人或电话，谢谢。
```
