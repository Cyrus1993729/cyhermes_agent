# 批量抓完之后的去重与归档

适用：一次抓了 N 篇公众号文章落进同一个目录（桌面/知识库），用户要求
「看看跟之前沉淀的有没有重复，别光比名字」以及「把相关文章归到一个文件夹」。

实测样本：2026-11-18，桌面上 19 篇（4 篇 11-12 旧抓 + 15 篇新抓，同一公众号「一味君」）。

## 一、去重：三层判据，从硬到软

### 第 1 层：原文链接完全相同（硬判据）

每篇转出的 Markdown 头部都有 `> 原文链接：https://mp.weixin.qq.com/s/xxx`。
纯文本读出来按链接分组，同一 URL 出现两次 = 同一篇。
**这一层能抓住「同一篇文章被两次抓取」，抓不住「同一篇被换标题转载/重新发布」。**

### 第 2 层：正文 5-gram Jaccard（抓转载、改标题、换排版）

```python
def norm(t):                       # 归一化：去元数据头、去图片占位、去模板尾
    t = re.sub(r'^>.*$', '', t, flags=re.M)
    t = re.sub(r'\[图片\]', '', t)
    t = re.sub(r'(推荐卖家需要的工具.*$|老铁们.*$|微信号.*$)', '', t, flags=re.M)
    return re.sub(r'\s', '', t)

sh = lambda t, n=5: {t[i:i+n] for i in range(len(t)-n+1)}
# 两两：同片段数 / 并集片段数
```

**中文不要用分词或 difflib.ratio 直接比**（同一作者的模板化开头会污染），字符 5-gram 集合最稳。
实测阈值：

| 情况 | Jaccard |
|---|---|
| 同一篇（排版略有差异） | **0.968** |
| 同系列上下篇（Codex 测算器上下篇） | 0.121 ← 实测**次高** |
| 其余任意两篇 | < 0.30 |

→ **> 0.30 就需要人工看；> 0.90 基本可判同一篇。**
先把归一化里的「模板段」（固定开场白、公众号推广尾、留言号召）去掉，否则整批同号文章相似度会被系统性抬高。

### 第 3 层：difflib 行级 diff —— 判断差异是「内容」还是「格式」

命中重复后**不要立刻删**，先跑 `difflib.SequenceMatcher(None, 旧行列表, 新行列表).get_opcodes()`：
只有 `replace` 且差异落在标题层级标记、`![图片]` vs `[图片]`、`**人名：**` vs `人名：`、抓取时间行
→ 判定「正文一字不差，纯格式差异」。本次 19 对里唯一一组重复就属于这种。

## 二、重复时保留哪一份：看结构质量，不看新旧

本次反直觉的结论：**新抓的那份反而更规范**。

- 旧版（11-12）把文首「框架目录」也标成了 `##`，导致目录和正文章节同级、结构失真
- 新版（11-18）目录转成 `- ` 列表、正文用 `##/###` 分层 —— 正是 skill 里「文首有目录」那条坑要求的样子

→ 判据写成可执行的：`grep -c '^## '` 与 `grep -c '^- [一二三四五六七八九十]'`。
**目录行被标成 `##` 的那份是劣质版。** 同质量时留新抓的（元数据/图片数更准）。

## 三、删除前先备份

用户说「去掉一个」也不要直接 rm：先 `cp` 到临时目录（本次 `%LOCALAPPDATA%\Temp\wx_xuanpin\removed_duplicate\`），
回执里写明备份路径，「要恢复随时说」。删完再跑一次全量相似度矩阵，确认剩余文件之间最高相似度已经很低（本次降到 0.121）。

## 四、归档：桌面整理惯例（本机）

用户说「把跟 X 有关的都放到桌面一个文件夹里」时：

1. **先 `ls -la` 全量看桌面**，不要只看刚放的那批——本次桌面上另有 4 篇同主题旧文，
   只处理新文件就会把归档做成残缺的。
2. **文件夹用短中文名**，跟既有风格一致（`各类api key` / `脚本` / `图片` / `文档` → 新建 `跨境电商`）。
3. 用关键词筛（`亚马逊/一味君/跨境/选品`）+ 只移动 `.md`，**别碰 `.lnk`、`desktop.ini`、既有文件夹**。
4. **归档目标里已经有「文档」这类杂项夹时，往它里面放，不要为两份文件另开一个文件夹。**
   本次两份散文档（OpenAI 合规核对、饮食记录方法论）都归入 `文档/`，桌面最终只剩快捷方式 + 5 个文件夹。
5. 移完**贴出完整文件清单**（逐条一行）+ 桌面剩余内容，不要让用户自己点开确认。

## 五、回执要点

- 去重结论要给出**判据和数字**：「只有 1 组重复，链接相同、相似度 0.968、逐行 diff 差异全在格式」，
  而不是「已去重」。用户原话就是「不要光对比名字」，他要看见你是怎么判的。
- 顺手报告**次高相似度**（本次 0.121）——这才能证明「其余真的不重复」，只说「没别的重复」等于没验。
