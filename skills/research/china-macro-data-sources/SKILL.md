# 中国宏观官方数据抓取

## 适用场景
用户要求检索中国宏观指标：PMI（制造业/非制造业/综合）、货物进出口（额/同比/顺差）、城镇调查失业率、青年失业率、CPI/PPI、GDP、社零、固投、人民币汇率（中间价/即期）等，并要求**数字 + 数据源 + as-of 日期**。

## 三条铁律（用户明确要求，务必内嵌）
1. **只检索，不编造**。任何数字必须来自真实抓取到的页面/接口；算不出、抓不到就直说缺口，不估算、不"合理推测"。
2. 每个数字带 **数据源（机构+稿件名/接口）+ as-of（数据期 + 发布日期）**。
3. 派生值（如 顺差=出口−进口）可以算，但**必须注明"据官方出口/进口额计算"**。

## 抓取策略：一手源优先，搜索引擎仅作辅助
**宏观官方数据直接直连一手发布页**，更权威且稳定。搜索引擎（Bing 等）在该 Windows 主机上经常被反爬（Cloudflare 验证码/兜底百科页），不要在那里耗时。已验证可用的一手端点清单与返回格式见 `references/endpoints.md`。

**搜索引擎仅作"定位一手 URL"的辅助手段**，且必须用反爬友好的端点：
- **Bing 经常被 Cloudflare 拦截**（2026-07-24 再次确认），不要依赖
- **DuckDuckGo HTML 端点可用**：`https://html.duckduckgo.com/html/?q=...`（UTF-8 预编码，curl 直接抓，返回 `<a rel="nofollow" class="result__a">` 列表）——用于发现 gov.cn / people.com.cn / xinhuanet.com 等一手 URL，再直连抓正文
- 搜索引擎结果页本身不产出最终数字，只用于找到一手端点

核心一手端点：

| 数据 | 一手源 | 发布节奏 |
|---|---|---|
| PMI | 国家统计局 zxfb 列表页 → 月末《中国采购经理指数运行情况》（统计局服务业调查中心+中物联） | 每月最后一天 09:30 |
| 失业率/贸易/CPI等 | 国家统计局 zxfb → 月中《X月份/上半年国民经济运行…》综合稿（贸易数据转引海关总署） | 每月15日前后 |
| 中间价 USD/CNY | 中国货币网(CFETS) `ccpr.json` | 每交易日 9:15 |
| 在岸即期 USDCNY | 新浪 `hq.sinajs.cn/list=USDCNY`（需 Referer，GBK 编码） | 实时 |

定位统计局稿件的流程：抓 `https://www.stats.gov.cn/sj/zxfb/`（分页 `index_1.html`/`index_2.html`…），正则提取 `<a>` 标题+href（形如 `./202607/t20260715_1964123.html`），按标题关键词（采购经理指数运行情况 / 国民经济运行）定位，再拼全 URL 抓正文。

## 坑（都是踩过的，直接照做）
1. **MSYS curl 的 `--data-urlencode` 把中文按 GBK 百分号编码**（`%c4%ea`…），不是 UTF-8 → 目标站收到乱码查询并弹验证码。**改用 Python `urllib.parse.quote(q)` 预编码后拼 URL 再 curl**。
2. **Windows/MSYS 下 Python 写出的文本文件可能带 `\r`**，shell 读后拼进 URL 会触发 curl `(3) Malformed input` → 读文件时先 `tr -d '\r'`。
3. **统计局网页表格有 rowspan**（"2026年"跨行），按纯文本正则切行会让奇偶月错位丢数据。**必须按 `<tr>`/`<td>` 逐行解析**再对列名。
4. **非制造业 PMI 正文段落给的"商务活动指数"与分项表是两张表**——以表格列名"商务活动"列为准，别拿错成分项值。
5. **青年失业率（16—24岁，不含在校生）不在月度国民经济综合新闻稿里**（综合稿只有全国城镇+31大城市+户籍分组）。它单独发布在统计局"数据发布"分年龄组失业率；若当时接口不可得，**如实标注缺口**，不要拿旧值或编造。
6. 中间价（CFETS 9:15 定盘）与即期行情是**不同口径**，并列给出时注明口径与点差，不要混为一谈。
7. 终端工具拒绝命令里的 `&` 后台符 → 多个 curl 用 `;` 串行执行即可，或分多次调用。

## 交付格式
按指标分节，表格列：指标 | 数值 | 同比/环比 | 数据源（机构+稿件） | as-of。末尾附证据文件路径。缺口单独列出并说明需要的官方出处。
