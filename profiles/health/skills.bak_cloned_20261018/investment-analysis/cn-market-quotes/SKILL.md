# 中国股市行情查询（腾讯接口）

## 触发
- 用户要求整理 A股/港股上市公司股价变化、板块涨跌、个股最新价
- 需要某只股票（如龙湖 00960、万科 A）的实时/收盘价、涨跌幅
- 财报/政策发布日看板块整体反应

## 数据源（无需授权，免费直连）
```
https://qt.gtimg.cn/q=sz000002,sh600048,hk00960,hk01109,...
```
- 代码格式：**必须带市场前缀** `sh`(沪) / `sz`(深) / `hk`(港)，逗号分隔，一次可查 30+ 只
- 国内接口：**不走代理**（`curl --noproxy '*'` 或 `urllib.build_opener(ProxyHandler({}))`），速度快
- 响应编码 **GBK**：必须 `raw.decode('gbk', errors='replace')`（UTF-8 直接乱码）
- 收盘时间：A股 15:00、港股 16:00（16:00 后查询即为当日收盘数据，含时间戳可核对）

## 字段解析（payload 按 `~` 分割）
| 索引 | A股 (sh/sz) | 港股 (hk) |
|---|---|---|
| [1] | 名称 | 名称 |
| [2] | 代码（**无前缀纯数字**） | 同 |
| [3] | 最新价 | 最新价 |
| [4] | 昨收 | 昨收 |
| [5] | 今开 | 今开 |
| [30] | 时间(日期 时间) | 时间 |
| [31] | 涨跌额 | 涨跌额 |
| [32] | 涨跌幅% | 涨跌幅% |
| [33] | 最高 | 最高 |
| [34] | 最低 | 最低 |
| [36] | 成交量(手) | 成交量(股) |
| [37] | 成交额(万元) | 成交额(HKD) |

## 多日涨跌（日K线接口）——"昨天+今天"两日报告
实时接口只能给"今天 vs 昨收"，要算"昨天 vs 前天"（或任意多日）的涨跌，需要日K线接口：
```
https://web.ifzq.gtimg.cn/appstock/app/fqkline/get?param=sz000002,day,,,5,qfq
```
- param 带市场前缀，A股/港股通用；`day`=日K线、`5`=最近5根、`qfq`=前复权
- 返回 **JSON（UTF-8）**，不是 GBK；路径 `data[code]["qfqday"]`，港股偶尔只有 `["day"]`——两个 key 都尝试
- 每根K线 `[日期, 开盘, 收盘, 最高, 最低, 成交量, ...]`，只需要 `[0]`(日期) 和 `[2]`(收盘)
- 昨日涨跌幅 = (倒数第2根收盘 − 倒数第3根收盘)/倒数第3根收盘；今日涨跌幅直接用实时接口 [32]
- ⚠️ 盘中查询时最后一根K线收盘是当日实时近似价，**今日口径永远以实时接口为准**（实时价才准）；K线按 `{日期: 行}` 建字典取值，不要裸依赖列表索引
- 周末/节假日返回最近交易日数据，先 `date` 确认星期再下结论

## 关键坑
1. 🔴 **返回的 [2] 是无前缀纯代码**——`hk00960` 查询返回的 [2] 是 `00960`，`sz000002` 返回 `000002`。**市场归属必须从查询列表自行映射**（用 `{纯代码: 市场}` 字典），否则全部行会 fallback 到同一分支。2026-08-31 实踩：初次脚本把 13 只港股全标成了 A 股
2. 名称字段含全角空格（如 `万  科Ａ`），展示前可 `.replace(' ','')` 清洗
3. 低价港股（0.05-0.2 港元级）涨跌额小数位多，格式化为 2-3 位小数时注意别丢精度
4. 探测"今天是否有交易"：先 `date` 确认星期几，周末/节假日查询返回的是上一交易日数据，向用户说明用的是最近交易日收盘

## 完整示例（python，execute_code 直跑）
```python
import urllib.request
codes = ["sz000002","sh600048","hk00960","hk01109"]
mk = {c[2:]: ("HK" if c.startswith("hk") else "A") for c in codes}
url = "https://qt.gtimg.cn/q=" + ",".join(codes)
opener = urllib.request.build_opener(urllib.request.ProxyHandler({}))
req = urllib.request.Request(url, headers={"User-Agent": "Mozilla/5.0"})
text = opener.open(req, timeout=15).read().decode("gbk", errors="replace")
for line in text.strip().split("\n"):
    f = line.split("=",1)[1].strip().strip('";').strip('"').split("~")
    if f[2] not in mk: continue
    print(mk[f[2]], f[1].replace(" ",""), "价", f[3], "涨跌幅", f[32]+"%")
```

## 延伸
- 板块整体表现：以标的清单批量查询后按市场分组排序（上涨/下跌家数、平均跌幅）
- 与财报分析配合：龙湖等个股在业绩预告/政策日的涨跌复盘（对照事件日期拉当日收盘）
- 政策/财报事件日复盘模板：批量两天数据（实时接口今日 + K线接口昨日）算两日涨跌表，再 web_search"日期+板块+大跌"归因消息面，一次交付"两日数据表+背景"。实例：2026-08-28 五部门地产新政 → 8/31 港股内房高开低走（越秀 -13.6%、融创 -10.4%），9/1 港股续跌、A股分化企稳
