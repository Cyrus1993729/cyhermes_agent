# 保值率与二手流动性评估（买什么/换什么最划算）

## 触发

- 「买 A 还是买 B 划算」「哪个保值」「闲鱼好不好出」
- 手里有**购物额度/补偿金/代金券**要换成实物（常见：索尼电视维保额度、京东卡、以旧换新补贴），目标是**变现或换到最大价值**
- 用户加约束：「可以接受少量加钱买更贵的再出」「要考虑保值率」

## 铁律：三层价格核对，别用官方价当锚

1. **官方建议零售价**（官网/官方商城）
2. **电商实际成交价**（京东/天猫/拼多多，注意平台补贴与黄牛溢价——可能高于官方价）
3. **二手真实成交价**（闲鱼近 7 日成交 > 挂牌价）

🔴 **挂牌价 ≠ 成交价**：高溢价期挂牌严重虚高，真实成交往往低 10-15%（实例：PS5 Pro 挂牌 7500-8000，玩家实测「挂一个月无人问津」；这个「高溢价挤压需求」的反向信号必须主动查证并告知用户）。

## 保值率分档（数码消费品经验序）

| 档 | 品类 | 典型折价 | 出手速度 |
|---|---|---|---|
| A 限量/典藏 | 十周年典藏耳机、限定版手柄、联名款 | 最小，可能溢价 | **慢，受众窄，接盘看运气** |
| B 硬通货 | 游戏主机、相机镜头（E 卡口/GM 定焦） | ~10% | 快，几天内出 |
| C 普通数码 | 主流耳机、播放器 | 15-25% | 中 |
| D 大件 | 显示器、电视、音箱 | **25%+** | 难：重、运费高、怕摔、买家少 |

⚠️ **限量 ≠ 抢手**：典藏/情怀品折价小是「理论值」，实际要赌有没有粉丝接盘，别把「限量」直接换算成溢价。

## 溢价窗口套利（加钱买更贵的唯一正确理由）

「加钱买更贵的再出」只有在**官方价 < 市场价**时才成立——即官方缺货/限购造成的倒挂。识别信号：官方渠道售罄或每日限量放货、电商第三方加价、二手价逼近全新价（差价 <1000）。

- 算账用 **净落袋**：`出手价 − 自付现金`，横向比对各方案（额度场景下「折价率最小」不是目标，「净落袋最大」才是）
- 必查：**额度能不能补差价超买**、有没有品类限制——先确认能买到，再谈加钱；买不到一切免谈
- 风险要讲透：窗口由缺货+涨价+补贴叠加而成，**补货或热度退潮即回落**；建议到手尽快挂出

## 出手难易度评估维度

重量体积（物流破损/运费谁承担）→ 受众广度（主机≫显示器）→ 保修与真伪顾虑（**带保修的国行最好卖**）→ 是否处于涨价周期（涨价期二手同步走强，甚至「白玩一年倒赚」）。

## 交付口径

- 给**量化对比表**（商品 / 官方价 / 二手成交区间 / 净落袋 / 增量），不要只说「这个保值」
- 结论必须带**决策顺序**（先确认买得到 → 再谈加不加钱 → 再说出手定价）
- 定价建议：低于市场价 10-15% 换取快速出手，并说明「压价换速度」的取舍

## 坑

- 用官方价算折价率 → 忽略渠道溢价与补贴，结论可能反向
- 把挂牌价当成交价 → 高估回款 10-15%
- 只看折价率不看绝对净落袋 → 在「有额度、零现金」场景下排序会错
- 忽略闲置成本与机会成本：额度本来就是白得的，能落袋的现金才是收益
