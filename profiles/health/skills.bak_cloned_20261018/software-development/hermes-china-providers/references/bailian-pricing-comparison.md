# 阿里云百炼 vs 官网直连：价格对比

> 调研日期：2026-07-31
> 结论：百炼第三方模型（DeepSeek、Kimi）标价显著高于官网直连价，即使考虑折扣也缺乏竞争力。

## DeepSeek V4 Pro

### 价格演变

| 阶段 | DeepSeek 官网 | 百炼标价 |
|---|---|---|
| 4月发布 | 原价12/24，2.5折=3/6 | 上线"与官网同价" |
| 5月31日 | **永久降为1/4**=3/6 | 未跟进 |
| 7月峰谷定价 | 非高峰3/6，高峰6/12 | 仍12/24 |

### 当前对比（元/百万token，输入/输出，北京地域）

| | DeepSeek 官网直连 | 百炼标价 | 百炼5折后 | 百炼6折后 |
|---|---|---|---|---|
| 非高峰（晚上/周末/午休） | **3 / 6** | 12 / 24 | 6 / 12 | 7.2 / 14.4 |
| 高峰（工作日9-12, 14-18） | **6 / 12** | 12 / 24 | 6 / 12 | 7.2 / 14.4 |

> 百炼销售人员声称"原价=官网定价"技术上正确（12/24 是 DeepSeek 最初老标价），但 DeepSeek 已将实付价永久降到原价1/4。百炼拿老标价打5-6折，5折后才与 DeepSeek 高峰价打平，非高峰仍贵1倍。

**来源**：
- DeepSeek 官网定价：https://api-docs.deepseek.com/zh-cn/quick_start/pricing
- 百炼定价：https://help.aliyun.com/zh/model-studio/model-pricing
- 峰谷定价：Yahoo Finance 2026年7月报道

## Kimi K3

| | Kimi 官网（估算） | 百炼标价 |
|---|---|---|
| 输入 | ~8 元 | **20 元** |
| 输出 | ~32 元 | **100 元** |

百炼 Kimi 系列限流：5 个模型**共享** 500 RPM + 300万 TPM，存在内部竞争。

**来源**：https://help.aliyun.com/zh/model-studio/kimi-k3

## 百炼 vs 直连：非价格因素

| 维度 | 百炼 | 官网直连 |
|---|---|---|
| API Key | 一个 Key 管所有模型 | 每家一个 Key |
| 供应商风险 | 单点故障（阿里云挂了全挂） | 厂商多样性 |
| 模型覆盖 | Kimi K3 用 `kimi/kimi-k3`，非 `kimi-k3` | 标准 model ID |
| 国内访问 | 阿里云基础设施，延迟低 | DeepSeek 官网高峰期可能繁忙 |
| Hermes 配置 | 一个 custom provider | 多个独立 provider |

## 结论

**除非百炼能谈到低于3折**（DeepSeek V4 Pro 输入<3.6元），否则价格上没有任何优势。维持 DeepSeek + Kimi 官网直连 + 千问走百炼 workspace key 的混合方案是最优解。
