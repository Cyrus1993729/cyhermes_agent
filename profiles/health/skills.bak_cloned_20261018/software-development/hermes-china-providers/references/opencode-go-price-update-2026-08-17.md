## 我们用量核算（state.db session_model_usage）

方法：迁移前稳定期（deepseek 官方 provider，7/31-8/16，16 天）日 token 量 → 外推月量 → 按新价格表计算：

```
日：in 0.37M / out 0.14M / cache 19.9M → 月：in 11.1M / out 4.3M / cache 597M
Off-Peak:  out 4.3×$0.66=$2.8 + in 11.1×$0.22=$2.4 + cache 597×$0.007=$4.2 = $9.4/月（63% 占用）
全 Peak:   out 4.3×$1.32=$5.7 + in 11.1×$0.44=$4.9 + cache 597×$0.014=$8.4 = $19/月（127% 超限）
```

**结论：从"随便用"（4.6%）变"接近顶格"（63-127%）**。日报 11:00/17:00 生成撞 Peak（×2 价格）。
