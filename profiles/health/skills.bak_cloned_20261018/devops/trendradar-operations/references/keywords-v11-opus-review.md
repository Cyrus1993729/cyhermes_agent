## Opus 审查发现的真问题（P0 类）

1. **两个死规则**：
   - `[跨境贸易摩擦]`（`+跨境` + `+贸易摩擦`）：要求同一标题字面含两个词，中文标题几乎不可能 → 永不命中 → 删
   - `[电商关税]`（`+电商` + `+关税`）：被宏观组裸"关税"完全覆盖（宏观早先命中），且命中率极低 → 删
2. **防串设计自相矛盾**：文件头写"关税/贸易摩擦不单用"，但 `[宏观经济]` 组里"关税/加征关税/贸易摩擦/反倾销"就是裸词单用 → 组合锁定形同虚设。解法：宏观组删 4 裸词，抽独立 `[关税与贸易战]` 组（`/对等关税|加征关税|关税豁免|关税战|301关税|232(关税|条款)|反倾销|反补贴|贸易战|贸易摩擦|出口管制|实体清单/`）+ `@6` 限流
3. **高频误伤词**（按危害排序）：消费（消费券/315 海量）、苹果（山东苹果/苹果醋）、黄金（黄金周/黄金档/黄金联赛）、仰望（仰望星空动词）、收盘/盘中/盘前（A 股行情噪音）、出口（高速出口）、AGI（子串命中 magic→荣耀手机）、麒麟（麒麟啤酒/麒麟区）、小米（小米粥）、灵犀（心有灵犀）、白银（白银市）、避险（地质灾害避险）、listing（delisting 退市）、Meta（metaverse/metal）、PPI（屏幕像素）
4. **全局过滤误杀**：`出轨` 吞掉列车出轨事故新闻（改 `明星出轨`）；`离婚` 误杀"上市公司实控人天价离婚"财经新闻（删）

## 关键写法修复

- **TikTok**：`TikTok Shop`/`TikTok 电商` 带空格，中文标题实际写「TikTok电商」「TikTok小店」→ 永不命中。改 `/tiktok\s*(shop|电商|小店|直播|带货|美国站|电商业务)/ => TikTok电商`（`\s*` 兼容空格）
- **Mercado Libre** → `/mercado\s*libre|美客多/`；**Coupang** → `/coupang|酷澎/`（补中文译名）
- **Listing/listing** 两行等价（匹配走 .lower()）→ 删一行；`(?<![a-z])listing` 防 delisting
- **英文边界**：`\b` 对中文无效（中文属 `\w`，官方模板 `\bDeepSeek\b` 在"字节的tiktok业务"会漏匹配）→ 一律 `(?<![a-z])xxx(?![a-z])`

## 解析器陷阱（frequency.py 实测，与文档不符处）

- `!` 过滤词**全局生效**：`filter_words` 是唯一扁平列表，遍历词组前统一检查命中即 return False。文档"仅限当前词组"是错的。排除方案用正则负向断言，不用 `!`
- `[WORD_GROUPS]` 标记**粘性**：current_section 是状态变量，误删标记行后整库关键词变全局过滤词 → 静默 0 推送无报错。文件内已加保护注释
- 组匹配语义（matches_word_groups）：所有 required（+词）都出现 AND 至少一个 normal（普通词）出现 → 组合锁定必须独立成组
- 空行分隔组：`content.split("\n\n")`，注释块独立会被跳过
