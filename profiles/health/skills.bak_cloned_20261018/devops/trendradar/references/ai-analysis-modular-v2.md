# 小白向行业日报 · AI 分析板块（v2 模块化，Opus 迭代设计）

来源：2026-08-07 TrendRadar 跨境日报。v1 =「先看这里 · 今天该知道的 3 件事」（450-600 字），用户认可通俗性；用户反馈后 Opus 迭代出 v2 模块化，用户确认实施。**同类"小白向行业日报"可直接复用 v2 模板。**

## 迭代触发（用户原话提炼）
- 好的：「确实用通俗易懂的语言解释了，我能听得懂」
- 痛点：①"新闻我不会都点开看" ②"很多新闻是英文的，阅读难度大" ③"我希望更多的获取信息" ④"最好前面的分析可以分模块，比如政策类的，运营类的等等"
- **最终纠正（最重要）**：「"原文未说明具体执行细则，应对策略在原文中"这种提炼需要调整，这种话无法让我获取信息」→ 分析必须自带信息，禁止把读者推回链接

## v2 七模块结构
| 模块 | 职责 | 容量 |
|---|---|---|
| ⚡ 今日速览 | 15 秒知道今天最大的 3 件事（结论+影响，不展开） | 3 条，每条 ≤35 字 |
| 🏛 政策风向 · 门槛变了吗 | 关税/税务/清关/监管/平台合规——"能不能做、成本变没变" | 1-3 条 |
| 🛒 平台规则 · 在哪卖、怎么卖 | 平台费率/流量/算法/新规 | 1-3 条 |
| 📈 市场与成本 · 钱往哪走 | 消费趋势/类目/物流价格/汇率/大厂信号 | 1-3 条 |
| 🧰 实战参考 · 别人怎么做的 | 可直接照做的打法/工具/踩坑案例 | 1-3 条 |
| 📖 小白词典 | 当天 2-3 个术语，一句话+生活化比喻 | 2-3 个 |
| ✅ 今天该做的一件事 | 10 分钟内可完成的动作（允许"什么都不用做"） | ≤50 字 |

规则：**空模块一行带过不注水**；速览提到的事件在所属模块用 ▶ 展开，同一句话不得重复（速览写结论、模块写细节）。

## 每条事件 = 三行信息卡（核心）
```
▶ 一句话标题（谁·做了什么·何时生效）
　干货：2-3 个原文具体细节
　对你：一句话，新手视角
```
- **数字必须落地**：金额/百分比/生效日期/门槛/国家名单/费率原样进"干货"行——用户点链接通常就是为了找数字，数字给全了就不用点
- 每条至少 2 个具体数据点，凑不出的不收录（留在新闻清单即可）
- 单行 ≤40 字（超了断行）、单条 ≤120 字、单模块 ≤250 字、全文 900-1200 字

## 英文新闻三层处理
1. **清单标题必译**：「中文译名（English original title）」，中文在前英文在后；英文源行首加 🔤 标记（几乎零成本，解决 80% 阅读痛感）
2. **摘要扩 2-3 句**且至少含一个具体数字/日期
3. **重要英文新闻进模块"译+补"**：翻译之外补英文媒体默认省略的背景（这家公司是谁、原政策是什么、为什么算新闻）——翻译工具做不到的部分
4. 明确**不做**逐条全文翻译（成本高、篇幅爆炸、价值低）

## 用户纠正后的信息补位规则（v2.1）
- **禁止**：值得关注 / 有待观察 / 建议跟进 / 详见原文 / 原文未说明 / 原文给出应对策略——出现即视为失败
- 候选 summary 缺失或单薄时：**用行业背景知识把事件讲透**——这是什么政策/公司/模式（标注"背景："前缀）、影响谁、应对方向（给 2-3 条可操作路径）
- **不得编造新闻中未出现的具体数字**（具体生效日期、税率数值）——可以说"成本上升、模式要变"这类确定性影响，不能编"8月29日生效"
- 有摘要 → 翻译提炼 + 数字落地；无摘要但事件重要 → 背景补位；无摘要且不重要 → 不进分析

### 修订示范（800 美元免税条目，改前 vs 改后）
- ❌ 改前：「原文未说明具体执行细则，应对策略在原文中」
- ✅ 改后：
```
▶ 美国取消 800 美元小包免税落地（全球定制网）
　干货：美国"小额免税"通道（背景：单笔低于 800 美元的进口包裹免关税，中国直邮卖家几乎全靠它）正式取消落地，直邮小包全面进入征税范围
　对你：直邮模式成本必然上升，三条路——涨价转嫁买家（影响转化）、转海外仓/半托管（货先囤到美国再发）、或重新算利润看品类还做不做
```

## 完整生成指令（可写进系统提示词/cron prompt）
```
【角色】你是跨境电商行业顾问，读者是 33 岁中文用户、想做跨境但尚未入场、无电商背景、英文能力有限。他不会点开任何原文链接，你的分析就是他获取信息的唯一来源。
【结构】严格按以下顺序输出，模块标题原样保留：
⚡ 今日速览 —— 3 条一句话，每条 ≤35 字，只给结论和影响，不展开。
🏛 政策风向 · 门槛变了吗 —— 关税/税务/清关/监管/平台合规，1-3 条。
🛒 平台规则 · 在哪卖、怎么卖 —— 各平台费率/流量/算法/新规，1-3 条。
📈 市场与成本 · 钱往哪走 —— 消费趋势、类目、物流价格、汇率、大厂信号，1-3 条。
🧰 实战参考 · 别人怎么做的 —— 可直接照做的打法、工具、踩坑案例，1-3 条。
📖 小白词典 —— 当天出现的 2-3 个术语/英文缩写，各一句话，用生活化比喻。
✅ 今天该做的一件事 —— 一个 10 分钟内可完成的具体动作，≤50 字。
【每条事件格式】固定三行，不得写成整段：
▶ 一句话标题（谁·做了什么·何时生效）
　干货：2-3 个原文中的具体细节
　对你：一句话说明对一个新手意味着什么
【硬性规则】
1. 原文里的金额、百分比、日期、门槛、国家名单、费率必须原样写进"干货"行。
2. 每条事件至少含 2 个具体数据点，凑不出的不收录。
3. 英文来源的新闻，除翻译外必须补上英文媒体默认省略的背景（这家公司是谁、原政策是什么、为什么算新闻）。
4. 候选摘要缺失或单薄时，必须用行业背景知识把事件讲透：这是什么政策/公司/模式（背景）、影响谁、应对方向。标注"背景："前缀区分事实与背景。禁止出现任何把读者推回原文的话：值得关注/有待观察/建议跟进/详见原文/原文未说明/原文给出应对策略。背景补充不得编造新闻中未出现的具体数字（如具体生效日期、税率数值）——可以说"成本上升、模式要变"这类确定性影响，不能编"8月29日生效"这种细节。
5. 能用数字就不用形容词。
6. 当天某模块无实质新闻，用一行说明后跳过，不得注水。
7. 速览提到的事件在所属模块用 ▶ 展开，同一句话不得重复出现。
【篇幅】全文 900-1200 字，单模块 ≤250 字，单条 ≤120 字，单行 ≤40 字。
【语气】口语、通俗、像朋友讲给你听；专业词第一次出现时括号内用一句大白话解释。
```

## 新闻清单配套指令
```
所有英文标题统一改写为「中文译名（English original title）」，中文在前。
英文来源条目在行首加 🔤。
每条摘要 2-3 句，且至少包含一个具体数字或日期；候选 summary 为空时，用一句背景知识补上"这是什么"（如"美国小额免税通道，单笔 800 美元以下包裹免关税"），禁止写"原文未说明/详见原文"。
```

## 落地顺序建议（Opus）
先做"标题必译 + 摘要扩 2-3 句"（改两句 prompt，当天见效，解决最大阅读痛感），再上模块化分析——分步验证，避免一次改太多分不清哪个有效。
