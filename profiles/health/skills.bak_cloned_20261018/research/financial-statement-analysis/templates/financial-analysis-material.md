# 财务分析材料组装模板（喂 Opus 用）

用法：复制本骨架，把 `<>` 替换为目标公司数据，写入
`C:/Users/Administrator/hermes_output/<公司>_<报告期>_opus.txt`，
再按 financial-statement-analysis 的 Step 4 调 Opus。

## 数据来源标注约定（最关键）
- `✓` = 官方/权威来源已核实（公司官网业绩稿、港交所公告、证券时报/财新/每经）
- `推` = 基于材料内数字的算术推导、或由相邻年份披露倒推
- 不确定的宁可标"推"或省略，**绝不编造**；材料里标了，Opus 输出才不会幻觉
- 半年报注意区分：业绩预告（区间值）vs 正式中报；营运数据可能含税口径

## ① 任务与输出要求（放 prompt 头部）

```markdown
# 任务
你是资深行业分析师。基于以下"<公司>（<代码>）<报告期>"材料，系统分析其财务状况。
所有数据来自公开披露（公司公告/官网/权威财经媒体），材料外数据不要引用。

分析要求（必须覆盖）：
1. 长周期趋势：从行业周期峰值到最新期，营收/利润/毛利率/负债/现金轨迹与关键拐点
2. 近三年同期半年报对比：关键指标 + 利润结构剧变拆解
3. 行业背景解读：行业总量变化 vs 公司幅度的共性/个体划分，同业位置
4. 业务布局评估：多业务公司评估转型/新业务对冲旧业务亏损的能力
5. 财务安全垫：结构成色 + 局限
6. 结论：一句话定性 + 核心结论 3-5 条 + 未来 1-2 年观测指标表 + 风险清单
输出要求：中文、每个判断带材料数据、（已核实/推算）标注、不给买卖建议。
```

## ④ 最新公告/预告要点（逐条 ✓）
- 归母净利区间、核心利润区间
- 经营现金流、债务压降、融资结构表述
- 到期债务排布（未来 2 年各品种到期额）
- 管理层目标原话（如"2027 恢复增长"）

## ⑤ 行业背景（✓ 统计局/中指/克而瑞/财新）
- 行业总量峰值→最新（销售额/面积/投资/新开工）
- 同业榜单（百强、千亿名单、民企 vs 央国企）
- 政策基调一两句

## ⑥ 业务布局（✓ 公司披露）
- 板块/航道构成、各板块收入与毛利率
- 新业务核心资产（门店数/出租率/客流增速）
- 战略表述（转型目标、资本开支计划）

## ⑦ 信息盲区说明
- 未披露项（减值明细、受限现金、表外负债、2028 后到期分布）——让 Opus 知道边界
